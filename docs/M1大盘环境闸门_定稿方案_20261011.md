# M1 大盘环境闸门 —— 定稿落地方案

> 版本：m1_v4_20261010　|　定稿日期：2026-10-11
> 适用模块：趋势动量量化系统 · M1（大盘环境层 / 闸门端）
> 状态：**已落地、已历史验证、已自动化每日落库**

---

## 一、定位与目标

M1 是整个趋势动量系统的**顶层闸门**，不负责选股、不负责精确买卖点，只回答一个问题：

> **当前大盘是否处在"胜率高、阻力小的简单局"，可以让下游 M2/M3 的板块突破信号被采信？**

- M1 输出一个 **env_coef（环境参与系数，0~1）**，作为 M2/M3 信号"是否置信、可不可采信"的闸门。
- M1 只筛**简单局**，顺势而为；没有简单局就全线等待，宁可空仓不做。
- fib 只调节**胜率置信度**，不直接决定仓位。
- 持仓周期由周线浪型决定：**周线上升 → 中线持有；周线下降 → 短线/不参与**。

---

## 二、核心设计原则

1. **人工锁定大框架，机械只在框架内算子浪。**
   金标准验证已证明：大趋势方向（牛熊、关键转折）无法从价格序列机械推导（3741 底在纯机械 zigzag 下永远无法确认，反弹仅 6.8%）。因此牛熊与关键浪型由人工锁定，机器只在锁定框架内定位子浪、算 fib、给闸门。

2. **fib 刻度定置信度，不定仓位。**
   回撤到关键斐波那契位，代表"调整到位、胜率提高"，给参与系数；不是越跌越加仓的仓位指令。

3. **周线 × 日线共振 = 最佳买点区。**
   周线大级别 fib 到位（大方向）× 日线末段跌透（时机），两层都到位才是高置信买点。

4. **破前低不归零（daily 层）。**
   调整末段经常破前低（带刺），历史验证：2025/4/7 十年大底当天日线就是破前低，归零会完美错过。

5. **证伪优先。**
   突破确认位才确认新推动；未确认前一律保守按调整浪计数。

6. **参数版本进日志。**
   每天快照记录算法版本，口径变更不污染历史，回测可复现。

## 三、整体架构

```
┌─────────────────────────────────────────────────────────┐
│  M1 大盘环境闸门                                          │
│                                                          │
│  weekly 闸门（周线层）                                     │
│    人工锁定 wave_labels（1-2-3-4-5 浪）                    │
│    4浪深度 = 已到达的最低低点算 fib                        │
│    确认位   = 4浪底后反弹高（上证=3995）                    │
│    突破确认位 → thrust（推进）；否则 → pullback（回调）      │
│                          │                               │
│  daily 闸门（日线层 = 周线子浪）                           │
│    末段下跌 r = 当前下跌幅度 / 前段反弹幅度                 │
│    与周线对称分档，破前低不归零                             │
│                          │                               │
│  嵌套：index_coef = weekly_coef × daily_coef              │
│                          │                               │
│  合成：env_coef = 四指数均值 × (1 − 0.5×分歧度)            │
│        任一指数周线破起点 → 硬闸门关闭（final=0）           │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
        env_coef 输出给 M2/M3 作为信号置信闸门
```

## 五、闸门规则详解

### 5.1 参与档位

| 档位 | 系数 |
|---|---|
| 空仓 / 闸门关 | 0.00 |
| 轻仓 | 0.35 |
| 重仓 | 0.70 |
| 全仓 | 1.00 |

### 5.2 weekly 闸门（周线层）

**A. bull_pullback —— 周线上升中，调整浪（2/4浪）回调**

基准 = 参考上涨段（4浪参考3浪整段，2浪参考1浪整段）

| 回撤比例 r | 系数 | 区段 |
|---|---|---|
| r < 38.2% | 0.00 | 回调未到位 |
| 38.2% ~ 50% | 0.35 → 0.70（线性） | 轻仓区 |
| 50% ~ 61.8% | 0.70 → 1.00（线性） | 重仓区 |
| 61.8% ~ 100% | 1.00 | 全仓区 |
| r ≥ 100% | 0.00 | 失效（破起点，重数） |

> **关键：r 用 4浪【已到达的最低低点】计算，不用反弹后的当前价。** 4浪实际回撤深度由最低低点决定，反弹不能让"回撤变浅"。

**B. bull_thrust —— 周线上升中，推动浪（1/3/5浪）推进**

基准 = extension 占上一推动浪幅度

| 推进度 e | 系数 | 区段 |
|---|---|---|
| e < 1.3 | 1.00 | 推进中（全仓） |
| 1.3 ~ 1.5 | 0.70 → 0.35（线性） | 追高收紧重仓 |
| 1.5 ~ 1.6 | 0.35 → 0（线性） | 收紧轻仓 |
| e ≥ 1.6 | 0.00 | 追高空仓 |

**确认位（证伪切换）：**
- 确认位 = 4浪最低点之后的反弹高
- 当前价 **> 确认位** → 切换 thrust（新推动确认）
- 当前价 **≤ 确认位** → 一律 pullback（保守按4浪回调）
- 上证确认位 = **3995.18**

### 5.3 daily 闸门（日线层 = 周线子浪）

与周线对称。当前处于周线调整（4浪）内部，判断日线最后一跌：

**末段下跌 r = 当前下跌幅度 / 前段反弹幅度**

| 回吐比例 r | 系数 | 区段 |
|---|---|---|
| r < 38.2% | 0.20 | 调整初 |
| 38.2% ~ 50% | 0.35 → 0.70（线性） | 轻仓 |
| 50% ~ 61.8% | 0.70 → 1.00（线性） | 重仓 |
| r ≥ 61.8% | 1.00 | 末段跌透（全） |

> **截断式，破前低（r≥1）保持满分 1.00，不归零**，仅标注"破前低·末段深跌"。
> 日线级别判断**以上证清晰五段为锚**；三指数更弱、子浪不清晰，但同为第五段运行中——跌幅越大，抄底胜率越高。

**企稳确认（daily 层止跌信号）：**
- 最近摆点为 bottom 且当前反弹：按反弹收复程度给分
- 突破前一反弹顶 → 企稳确认（重仓）；收复 ≥50% → 企稳反弹（轻仓）

### 5.4 嵌套与合成

**单指数：**
```
index_coef = weekly_coef × daily_coef
```

**四指数合成 env_coef：**
```
raw_coef   = mean(四指数 index_coef)
divergence = std(四指数 index_coef)          # 分歧度
env_coef   = raw_coef × (1 − 0.5 × divergence)
```

**硬闸门：** 任一指数周线 ratio ≥ 1（破起点）→ env_coef = 0（系统性风险会传染，不软化）。

**环境标签：**

| env_coef | 标签 |
|---|---|
| ≥ 0.80 | 共振·闸门大开 |
| 0.60 ~ 0.80 | 偏多·闸门半开 |
| 0.35 ~ 0.60 | 分歧·降权观察 |
| < 0.35 | 弱势·闸门收紧 |

## 八、历史验证

### 验证样本：2025-04-07 上证2浪大底

| 层级 | 状态 | 信号 |
|---|---|---|
| 周线 | fib 回撤 61.0%（1浪 2635→3674，回到 3040） | 0.98 重仓 |
| 日线 | 末段下跌 115%（破前低·末段深跌） | 1.00 满分 |
| **周线×日线共振** | | **0.98 满仓信号** |
| 后续实际 | 2浪底 3040 → 3浪顶 4258 | **+34.9%（约+40%）** |

**验证结论：**
1. 周线×日线共振有效：当天两层满格（0.98×1.0），后续真涨约35%。
2. "破前低不归零"正确：2浪底当天日线就是破前低（3140→3040，r=115%），老规则归零会错过十年大底。
3. "最低低点算深度"正确：2浪最深就是3040那天，用最低低点才算到61%。
4. 2浪(61%深) vs 4浪(42.5%浅)被自然区分，符合波浪交替原则（2浪深、4浪浅）。

## 十四、与 M2/M3 对接

- M1 输出 **env_coef**，作为 M2/M3 板块突破信号的置信闸门：
  - env_coef 高（简单局）→ M2/M3 信号可采信，正常参与
  - env_coef 低（复杂局/弱势）→ M2/M3 信号降权或不采信
- 对接时不改冻结文件，另起模块读取 env_snapshot / 调用闸门函数。

## 附：波浪理论在 M1 中的用法（一句话）

> **铁律用来排除错误（I2/I3/I4），fib 用来定位胜率区间，确认位用来证伪切换，多解性用"人工锁框架 + 硬切换"容纳。**
> M1 不预测，只在"周线到位 × 日线跌透"的共振区打开闸门。
