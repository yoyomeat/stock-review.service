## 一、定位与目标

M1 只回答一个问题：**现在允许不允许建立新风险（新仓/加仓）？**

- **只控入场**：出场、止盈止损全部归 M2/M3 技术面规则，M1 一个字不碰
- **上升浪中默认开门、越涨越买**：不主观找顶，不设任何"涨多了收紧"的反趋势阈值
- **关门条件唯一**：确定上升浪结束、进入四浪调整（困难局不打）——确认跌了才停（越跌越卖），不在涨的时候收
- **开门条件**：回调空间到位（fib 的唯一用途）+ 拐点确认（胜率验证过的触发器）
- 持仓周期仍由周线浪型决定：周线上升 → 中线持有；周线下降 → 短线/不参与

---

## 二、核心设计原则

1. **人工锁定大框架，机械只在框架内算子浪**（实证：机械数浪对大级别转折滞后 120~312 交易日，见 v2 附录）
2. **fib 只管两件事**：① 回调空间是否到位 ② 拐点胜率定位——不参与任何仓位/收紧梯度
3. **越涨越买、越跌越卖**：上升浪不设收紧阈值（v2 的 extension 1.3/1.5/1.6 阶梯作废）；
   风险释放发生在"确认跌了"之后，不在"涨得高"之时
4. **拐点必须胜率验证**：所有开关触发器先过历史前瞻收益检验（触发日之后真跌/真涨才配做开关）
5. **证伪优先**：未确认前保守；确认位状态机保留，用于周线级浪位确认与破位重数
6. **参数版本进日志**：algo_version 升版，历史快照不回改

## 三、闸门状态机（定稿）

```
【开门态】默认态 = 上升浪中，越涨越买，无任何收紧
    │
    │ 关门触发 C2a（单层，用户拍板）：
    │   收盘 < 运行高点 − 38.2% × 最近大级别推进腿幅
    │   （推进腿 = 8% zigzag 最近已确认摆动底 → 运行高点）
    │   波浪语言：对前一推进段回撤 ≥38.2% = 不再是回踩，是调整 → 确认进入四浪调整
    ▼
【关门态】困难局：禁新仓（存量仓出场归 M3 纪律）
    │
    │ 空间到位（fib 唯一职责）：
    │   r = (运行高点 − 运行低点)/推进腿幅 ≥ 61.8%  或  破前低（r ≥ 1）
    │
    │ 开门触发 S1（用户拍板）：
    │   大级别摆动底确认（8% zigzag 摆动底确认日）且 空间到位
    ▼
【开门态】新一轮上升浪，回到顶部循环
```

**确认位状态机（保留，周线级辅助）**：最低低点后的反弹高为确认位；收盘突破 = 新推动确认
（上证机械复现 3995.18）；跌回确认位下 = 证伪退回保守；破起点（r≥1）= 数浪失效须重数。

## 四、规则参数与数据依据

### 4.1 关门触发 C2a（唯一关门条件）

| 项 | 值 | 依据 |
|---|---|---|
| 阈值 | 从运行高点回撤 **38.2%** × 大级别推进腿幅 | 波浪理论"调整确认"位；与 fib 空间语言同源 |
| 推进腿尺度 | 8% zigzag 已确认摆动底 → 运行高点 | 六候选对比中唯一"触发后真跌"的规则 |
| 顶后滞后 | **3~5 个交易日** | 远快于周级结构破坏（数周），满足"及时"要求 |
| 误触发率 | 11.7~12.8%（上升腿中途误关） | 8 条腿错关 1 条，代价=漏涨 8%（S1 会重开） |
| 触发日前瞻 | 20 日 **−1.8%（胜率 35%）** | 全表唯一"关了门之后真在跌"的规则 → 关门有效 |

对比淘汰：破摆动低点(sdw) 触发后反而 +4%（胜率 70%）——它是 M3 出场信号，不是入场关门信号；
失守 MA20 误触发 80%+；高点回撤 8% 滞后 12~15 天；4% 反转确认仅中性。

### 4.2 开门触发 S1 × 空间到位

| 项 | 值 | 依据 |
|---|---|---|
| 触发 | **大级别摆动底确认（8% zigzag 确认日）** | 开关回测选型：跨序列一致性 5/5（4% 版本 3/5 且年均 27~35 次抖动） |
| 前置 | 空间到位 r≥61.8% 或破前低 | 浅回调区任何起涨信号胜率 ≤55%（−1.6%），深区 65~81%——fib 只管空间 |
| 尺度注记 | 4% S1 为子浪级，会在复杂调整中反复假拐点 | **S1 的尺度参数由数据定为 8%**；如需改回 4% 一句话可调 |

### 4.3 空间到位（fib 的唯一用途）

```
r = (运行高点 − 运行低点) / 最近大级别推进腿幅
r ≥ 61.8% → 空间到位（回调跌透）；r ≥ 1（破前低）→ 同样到位（深跌挖坑）
r < 61.8% → 空间未到位，任何起涨信号不采（假拐点区）
```

### 4.4 复合口径（四指数）

- 状态机在四个指数上独立运行（上证/深成/创业板/科创50）
- **全局关门 = 任一指数触发 C2a**（保守，复杂局会传染）
- **全局开门 = ≥2 个指数同时 S1×空间到位**（单指数假拐点不采）
- 板块篮子状态仅作参考显示（口径注记：篮子几何与指数不同步时以指数为准）
