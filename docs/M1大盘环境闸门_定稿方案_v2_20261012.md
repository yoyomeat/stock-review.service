## 一、定位与目标

M1 是整个趋势动量系统的**顶层闸门**，不负责选股、不负责精确买卖点，只回答一个问题：

> **当前大盘是否处在"胜率高、阻力小的简单局"，可以让下游 M2/M3 的板块突破信号被采信？**

- M1 输出 **env_coef（环境参与系数，0~1）** 与**三段决策（full / observe / reject）**，
  作为 M2/M3 信号"是否置信、可不可采信"的闸门。
- M1 只筛**简单局**，顺势而为；没有简单局就全线等待，宁可空仓不做。
- **M1 管"新风险"，不管"存量仓"**：只控制新开仓的速度与额度，绝不因环境弱而砍趋势中的持仓
  （出场是 M3 的纪律，任何环境下都执行）。
- fib 只调节**胜率置信度**，不直接决定仓位；持仓周期由周线浪型决定：
  **周线上升 → 中线持有；周线下降 → 短线/不参与**。

## 二、核心设计原则

1. **人工锁定大框架，机械只在框架内算子浪。**
   本次已用数据实证（见第六节）：纯机械数浪对大级别转折（1浪顶/2浪底）识别滞后 120~312 个交易日，
   不可用于驱动闸门；牛熊与关键浪型由人工锁定，机器只在锁定框架内定位子浪、算 fib、给闸门。
2. **fib 刻度定置信度，不定仓位。** 回撤到关键斐波那契位代表"调整到位、胜率提高"，不是越跌越加仓的仓位指令。
3. **周线 × 日线共振 = 最佳买点区。** 周线大级别 fib 到位（大方向）× 日线末段跌透（时机），两层都到位才是高置信区。
4. **破前低不归零（daily 层）。** 调整末段经常破前低（带刺），历史验证：2025/4/7 十年大底当天日线就是破前低，归零会完美错过。
5. **证伪优先。** 突破确认位才确认新推动；未确认前一律保守按调整浪计数；确认后跌破确认位则退回保守。
6. **决策只用两端。** 644 日测试证明中间档无历史边际：≥0.8 全信、<0.35 拒绝、中间观察不表态（诚实口径）。
7. **参数版本进日志。** 每天快照记录算法版本，口径变更不污染历史，回测可复现。

```

│  M1 大盘环境闸门                                          │
│                                                          │

│    确认 → thrust（推进）；未确认 → pullback（回调）          │
│                          │                               │

│    末段下跌 r = 当前下跌幅度 / 前段反弹幅度                  │

│  嵌套：index_coef = weekly_coef × daily_coef              │

                          │
```

## 五、闸门规则详解

### 5.1 参与档位

| 档位 | 系数 |
|---|---|
| 空仓 / 闸门关 | 0.00 |
| 轻仓 | 0.35 |
| 重仓 | 0.70 |
| 全仓 | 1.00 |

### 5.2 weekly 闸门（周线层）

**A. bull_pullback —— 周线上升中，调整浪（2/4浪）回调**（基准 = 参考上涨段：4浪参考3浪整段，2浪参考1浪整段）

| 回撤比例 r | 系数 | 区段 |
|---|---|---|
| r < 38.2% | 0.00 | 回调未到位 |
| 38.2% ~ 50% | 0.35 → 0.70（线性） | 轻仓区 |
| 50% ~ 61.8% | 0.70 → 1.00（线性） | 重仓区 |
| 61.8% ~ 100% | 1.00 | 全仓区 |
| r ≥ 100% | 0.00 | **破起点 = 数浪失效，须重数（硬闸门）** |

> **r 用 4浪【已到达的最低低点】计算，不用反弹后的当前价。** 反弹不能让"回撤变浅"。

**B. bull_thrust —— 周线上升中，推动浪（1/3/5浪）推进**（基准 = extension 占上一推动浪幅度）

| 推进度 e | 系数 | 区段 |
|---|---|---|
| e < 1.3 | 1.00 | 推进中（全仓） |
| 1.3 ~ 1.5 | 0.70 → 0.35（线性） | 追高收紧重仓 |
| 1.5 ~ 1.6 | 0.35 → 0（线性） | 收紧轻仓 |
| e ≥ 1.6 | 0.00 | 追高空仓 |

**C. 确认位状态机（v2 核心修订，替代 v1 的"当前价 vs 确认位"单点比较）**

```
确认位 = 最低低点之后、截至【前一日】的反弹高（running max，不含当日 high）
状态机逐日推演（确定性、无前视）：
  未确认：当日收盘 > 确认位 → 确认新推动（thrust），确认位【冻结】为失效线
          否则 → 一律 pullback（保守按4浪回调，证伪优先）
  已确认：当日收盘 ≤ 失效线 → 证伪，退回 pullback（反弹高重新累积）
          否则 → 保持 thrust
```

- 确认位是**结构水平**，不随新高上移（杜绝横跳）；上证当前机械复现 **3995.18**（= 5-1 浪顶）。
- v1 bug 注记：v1 取"运行最高 high（含当日）"且比较对象是 close，数学上恒不成立，thrust 永不触发——v2 修复。

### 5.3 daily 闸门（日线层 = 周线子浪，两态化）

与周线对称：末段下跌 r = 当前下跌幅度 / 前段反弹幅度。以上证清晰五段为锚。

| 状态 | 判定 | 系数 |
|---|---|---|
| **末段跌透** | r ≥ 61.8%（含破前低 r≥1，不归零，标注"破前低·末段深跌"） | 1.00 |
| **企稳确认** | 突破前一反弹顶 / 收复 ≥50% | 0.70 / 0.60 |
| 其余（含"调整初"） | — | **0.50 中性（不罚不奖）** |

> v1 的 0.20→1.0 四档斜坡经 644 日测试无预测力（"调整初"罚档前瞻反而好于中间档），已废除。
> 周线 thrust 期的子浪推进沿用 thrust 阶梯（1.3/1.5/1.6）。

### 5.4 嵌套、合成与决策

**单指数：** `index_coef = weekly_coef × daily_coef`

**四指数合成：**
```
raw_coef   = mean(四指数 index_coef)
divergence = std(四指数 index_coef)
env_coef   = raw_coef × (1 − 0.5 × divergence)
```

**硬闸门（相位修正）：** 任一指数周线 **pullback 且 r ≥ 1（破起点）** → env_coef = 0，输出"数浪失效·须重数"。
thrust 的 extension 不参与破起点判定（1.0~1.3 为"推进中全仓"）。

**决策三段（对接 M2/M3 的唯一口径）：**

| env_coef | 决策 | 标签 | 语义 |
|---|---|---|---|
| ≥ 0.80 | **full** | 共振·闸门大开 | 全信，新风险正常进入 |
| 0.35 ~ 0.80 | **observe** | 观察·无历史边际 | 不表态，新风险只允许试探仓 |
| < 0.35 或硬闸门 | **reject** | 弱势·闸门收紧 / 数浪失效 | 拒绝新风险 |

## 十四、与 M2/M3 对接

对接原则与动作矩阵详见**《M1测试结论与M2M3接入用法_20261012.md》**。一句话：

> M1 的三段决策只控制 **M2/M3 新风险的进入速度与额度**（full=全流程 / observe=仅试探仓 / reject=禁新仓）；
> M2 的信号生成规则、M3 的出场纪律**零改动**。
