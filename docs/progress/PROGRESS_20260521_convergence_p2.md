## 三、P2 Screener 设计方案（已实现）

### 3.1 最终参数

| 参数 | 值 | 依据 |
|------|------|------|
| 触发 | 反弹确认期 | cycle_label含"反弹确认" |
| 板块 | D日KPH TOP1板块 | 板块延续性88.9% |
| 选股池 | TOP1板块内涨停的20cm/10cm个股 | 20cm优先 |
| 换手率 | <5% | TO<5%为核心筛选条件 |
| 排序 | 20cm优先，同类型按涨幅降序 | — |
| 选股数 | 1只 | 单票集中 |
| 买入 | D日尾盘 | buy_timing=close |
| 持有 | D+2开盘卖出 | hold_days=2, exit_timing=open |

### 3.2 Alpha来源

反弹确认期D日KPH TOP1板块的涨停股，D+2跳空高开惯性。
- 20cm涨停 TO<5%: D+2 open avg=+12.29%, pos=86%
- 10cm涨停 TO<5%: D+2 open avg=+6.31%, pos=74%

### 3.3 代码实现

**已实现文件**：
- `quant/strategies/screeners/convergence.py` — `_select_p2()` 函数
- `quant/strategies/screeners/__init__.py` — 注册到 SCREENER_REGISTRY
- `config/strategy_rules.py` — STRATEGY_EXIT_RULES 新增 convergence_p2

**实现要点**：
- P1/P2 通过 cycle_label 自动分流（反弹确认期→P2，下降期→P1）
- 共用 `select_convergence` 入口函数
- P2 从KPH精选50取TOP1板块，筛选涨停股（10cm>=9.5%，20cm>=19.5%）
- 换手率<5%（从CSV获取精确数据）
- 20cm优先排序
- buy_timing=close（D日尾盘买），exit_timing=open（D+2开盘卖）
