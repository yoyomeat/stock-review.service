## 一、分析背景

在修复 regime 切换幽灵持仓 bug 后，回测总收益从 +45.50%（虚高）变为 -40.45%（真实）。本次分析使用架构文档规定的正确口径（D日cycle → D+1收益）对亏损原因进行深度归因。

## 二、分析口径（铁律）

```
D 日: review生成
  ├─ cycle_label, sentiment_score, profit_score  → 反映D当天市场状态
  └─ trade_plan.picks                            → D日生成，D+1才执行

D+1 日: 以开盘价执行D日的picks → 产生实际收益
```

**归因方式**：D日的cycle_label → D+1的profit_score

⚠️ 之前错误使用了 `market_style`（主升/退潮/轮动/抱团）作为 cycle 分析维度，实际应该用 `cycle_label`（上升期/下降期/冰点期/反弹确认期/确认震荡期）。

### 3.2 三大核心问题

**问题 1：冰点期开仓过多**
- 64天冰点期，81%有picks，平均37%仓位
- D+1 profit仅39.3，48%天赚钱效应差
- 冰点期应空仓等待，但策略频繁开仓

**问题 2：上升期选股D+1表现差**
- 上升期第1天：D+1 profit=43.0，47%天差
- 上升期第2天：D+1 profit=35.1，60%天差
- 上升期第3天：D+1 profit=39.2，50%天差
- 所有上升期子阶段的D+1 profit均低于50（中性线）

**问题 3：下降期仍在开仓**
- 下降期第1天：64%有picks，32%仓位
- 下降期第2天：75%有picks，38%仓位
- 下降期第3天：50%有picks，D+1 profit=20.7（极差）

### 3.3 全局结论

**没有任何cycle的D+1平均profit超过50。** 这意味着：
- 不管处于什么市场周期，策略选出的股票D+1赚钱效应都偏差
- 问题不仅在于"什么周期开仓"，更在于"选的股票本身不行"
