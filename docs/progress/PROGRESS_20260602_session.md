### 分析背景

### 分析方法

- 数据范围：338 天 review JSON + KPH 精选50 + 个股日线 CSV
- 覆盖：上升期 126 天 + 上升分歧日 26 天

### 核心发现

| 对比 | 上升期 | 上升分歧日 |

| TO<3% + LB≥2 | +1.72%/57.7% ✅ | -2.25%/52.4% ❌ |
| alpha 逻辑 | 低换手 + 连板惯性 | 低换手 + 低排名板块（逆向） |

| 发现 | 数据 |
|---|---|
| **cycle_day 是决定性维度** | Day2 必亏（-2.73%），Day3-4 最强（+3.28%/63.8%） |

| 发现 | 数据 |
|---|---|

## 三、情绪流框架讨论 — 三环模型

### 核心命题

```
alpha = 择时(cycle) × 主题确认(主线) × 资金聚焦(CONC)
```

### 达成共识

| # | 共识 |
|---|---|
| 1 | cycle 只做"做不做/做多大"，不做复杂策略路由 |
| 2 | CONC 是资金聚焦信号，有滞后但不可避免，仍有价值 |
| 3 | 主线确认是缺失的核心能力，需要新建 |
| 4 | CONC 和主线确认应互补确认，不是替代 |
| 5 | 下降期有特殊机会（抱团抵抗），需单独研究 |
| 6 | 下降期的 alpha 在抱团方向，和上升期逻辑一致（资金集中处有 alpha） |

### 下降期特殊性

| 周期 | 情绪形态 | 资金行为 | alpha 来源 |
|---|---|---|---|
| 上升期 | 扩散、追涨 | 分散进攻 | 主线延续 + 惯性 |
| 下降期 | 收缩、防御 | 团抱团 | 团抱团的赚钱效应 |
| 冰点期 | 恐慌、割肉 | 离场 | 恐慌反弹 |

### 重构方向

当前：`cycle → 路由到 screener → 技术指标选股`
目标：`cycle 做不做/做多大 → CONC+主线确认 定方向 → 主线方向内选股`
