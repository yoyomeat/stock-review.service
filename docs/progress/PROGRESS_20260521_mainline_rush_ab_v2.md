## 二、推翻的旧假设

### 2.1 换手率不是区分因子

旧假设：低换手率 = TOP股（原文档 TOP 中位 7.29% vs BOT 10.41%）

实际验证（10cm涨停股，n=1484）：

| 换手率 | n | D+4均值 | D+4胜率 |
|--------|---|---------|---------|
| 0-3% | 198 | +0.80% | 46% |
| 3-5% | 231 | -0.78% | 45% |
| 5-7% | 222 | +0.86% | 47% |
| 7-8% | 74 | -1.34% | 38% |
| 8-10% | 167 | +0.61% | 49% |
| 10-15% | 261 | +0.31% | 45% |
| 15-20% | 121 | -1.91% | 43% |
| >20% | 210 | -1.55% | 40% |

**结论：全量10cm涨停股D+4≈0%，换手率无单调关系。原文档TOP组+15%是事后归因偏差。**

### 2.2 连板数不是区分因子

### 2.3 龙头标签不是区分因子

| rank_tag | TOP10 D+4 | BOT10 D+4 |
|----------|-----------|-----------|
| 龙一 | +12.32%/94% | -14.00%/0% |

### 2.4 D+1 gap 不是区分因子

TOP无论gap正负都赚22-34%，BOT都亏。gap无区分力。

## 五、筛选参数定稿

### 5.1 最终筛选条件

| 参数 | 值 | 依据 |
|------|------|------|
| cycle_day | 4-6 | Day 1-3全量亏钱，Day 7+衰竭 |
| 板块 | CONC板块（KPH精选50） | 板块延续性88.9% |
| 成交额 | ≥30亿 | 30亿+ D+4=+9.99%/87% |
| 量比 | <1.2（温和放量/缩量） | 量比反向关系，TOP组量比<BOT组 |
| 优先 | 10cm | 10cm D+4=+11.29%/84% vs 20cm +7.59%/74% |
| 日均 | ~2.6只 | 聚焦 |

| 日均只数 | 2.6 |
| 总笔数 | 31 |
| D+4均值 | +9.99% |
| D+4胜率 | 87% |

| Cycle Day | 持仓 | 卖出 | 均值 | 胜率 | 逻辑 |

### 5.4 Alpha来源

Day 4-6 是上升期"大资金吃饭局"：
- 板块已确认强势（CONC信号在Day 1-3触发，Day 4-6延续）
- 大资金从容建仓中大盘股（成交额30亿+、量比<1.2 = 不爆量）
- 板块内成交额排4-10名的"中军"标的最优
- 不追涨停、不追连板，买的是机构建仓的容量标的
