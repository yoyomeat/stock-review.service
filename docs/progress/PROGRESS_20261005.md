# PROGRESS 2026-10-05 — 实验 #39 流动性/量能族研究

## 问题（用户）
单股涨幅无正向相关（#37/#38）之后：与流动性或者量能有正向关系吗？

## 方法
成员级量能形态族（stock_daily.db 成交量/额/换手 × 成分映射）× 6 时点（k=5/10/20/30/45/60）：
amt_exp 板块量能扩张 / share_ch 份额变化 / breadth 成员放量宽度 / conc_top5 额集中度 /
turn_exp 换手扩张 / m_amt_exp 成员额扩张。评价=赢家/其余中位+秩相关 vs MFE250。

## 结果（全部 IC≤0.13，多数≈0）
- breadth 成员放量宽度：证伪且略负（赢家 k=30 0.46 vs 其余 0.52）
- conc_top5 额集中度：方向略反（赢家 0.30~0.34 vs 其余 0.21~0.24——主线板块有大市值真龙头
  参与使额集中，但 IC≈0 无选择力；额集中≠收益集中，口径警示）
- share_ch：k=5 +0.13 后速衰；turn_exp：k=60 +0.13（后置，与"放量是涨出来之后的事"互证）
- amt_exp / m_amt_exp：全程≈0

## 结论
1. 量能/流动性不是独立信息源，是价格行为的影子。
2. 量能族唯一持续有效 = #35 vol_asym（涨日放量−跌日缩量，行为特征）。
3. 宽度要读**价格行为**（#31 成员站上均线占比 IC 0.19），不是量能行为。
4. 绝对流动性负向（#30）+ 本实验无正向 → 流动性/量能维度探索完毕。
