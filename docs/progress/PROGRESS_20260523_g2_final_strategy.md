## 六、最终策略

### 6.1 策略定位

| 项目 | 内容 |
|------|------|
| 路由 | A路径：hold + 游资主导 + 上升期 Day 3-6 |
| Alpha来源 | **流动性溢价 + 板块动量延续** |
| 预期收益 | D+2 open: +7.83%/87% |
| 与G1差异 | G1靠缩量连板(TO<3 & 2+连板)，G2靠大票流动性(>=10亿) |

### 6.2 D日筛选

```
CONC板块内 D日涨停(10cm) + 成交额 >= 10亿
```
- G2天数：33天/40天有信号
- 每日候选：约2.9只
- 一字率：仅13%（大多数可操作）

### 6.3 D+1执行

```
D+1 09:15 开盘前:
  对所有候选股挂涨停价排板

D+1 09:30 开盘后:
  一字涨停(13%) → 排板可能成交
  非一字(87%) → 盘中涨停封板时追入

Day 6 特殊规则:
  跳过一字排板，只做非一字封涨停追入
  （Day 6一字涨停D+2_OC=-0.23%，亏钱）
```

### 6.4 持有与卖出

```
D+2 09:30 开盘: 全部卖出（无论盈亏）
唯一例外: D+2一字涨停 → 持有到D+3开盘卖出
```

### 6.5 不需要止盈止损

与G1一致。D+2 open固定卖出最优。止盈砍赢家，止损无实质改善。
