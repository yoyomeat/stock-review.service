## 九、根因总结

1. **ice_point 策略在极端悲观市场中持续抄底，但市场持续下跌，反复止损**
   - 冰点期 65 天，累计 -76.4%，胜率仅 28%
   - 所有仓位区间全部亏损，无一例外

2. **低情绪（comp<40）时系统不应持仓**
   - 109 天累计亏 -46.2%
   - 低仓位（0-19%）64 天累计亏 -48.8%

3. **中性情绪（comp 40-60）是最优交易区间**
   - 111 天贡献 +77.9%，胜率 59%

4. **高仓位（80%+）是主要利润来源**
   - 62 天贡献 +87.8%，但需要在对的情绪环境下使用

**架构约束**：根据 ARCHITECTURE.md 原则，阈值应放在 config/strategy_rules.py，过滤在 quant/filters.py，策略函数只做计算。

### 11.10 结论

1. **冰点期不是全面亏损，prof才是关键变量**
2. **prof=0（极端恐慌）反而盈利**，因为恐慌后往往反弹
3. **prof 1-10（弱但非极端）是最大杀手**，21天亏-29.83%，胜率仅19%
4. **prof 21-30（中等偏弱）第二大亏损区**，8天亏-21.08%
5. **prof 11-20 和 prof 30+ 可以参与**，接近盈亏平衡或盈利
6. **过滤prof 1-10和21-30后，冰点期从-41%变为+7%**，改善48个点
