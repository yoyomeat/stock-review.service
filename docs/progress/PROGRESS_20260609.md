### 2.3 三大差距根因

#### 差距1：仓位严重衰减

- `_alloc(fp)` 的 `per_cap = fp * 0.6`，单票上限 54%
- V4 无此限制，单票可拿满仓 84%

#### 差距2：55天"幽灵pick"（V4不买，系统买了）

- CANDIDATE 37天 + CONFIRMED 18天
- 共同特征：**mainline_pool 为空**，但 leader_pool 非空
- V4 要求 pool 有 top1 才买，系统通过 leader_pool fallback 选了股票

**根因**：`mainline_tracker.py` 中 CANDIDATE 创建时 `mainline_pool=[]` 硬编码空。

诊断数据：
- CANDIDATE pool 空: 172 条（全部）
- CONFIRMED pool 空: 0 条
- CANDIDATE→CONFIRMED 转换时 pool 从 strong_pool 填充

#### 差距3：多股票分散

- V4 多主线时每个板块各买 top1（仓位可超 100%）
- 系统被 `_alloc(3)` 的 60% per_cap 限制，分散到多只

## 三、修复方案

遵循架构铁律：
- 原则1：单一修改点（每个 fix 最多影响 2 个文件）
- 原则2：禁止反向依赖（config 不 import quant）
- 原则3：策略函数只做计算
- 原则4：改前记录改什么/为什么/怎么验证

### Fix A: CANDIDATE pool 初始化

**文件**：`quant/mainline_tracker.py`
**改动**：CANDIDATE 创建时从 strong_pool 初始化 mainline_pool（与 CONFIRMED 一致）
**原理**：pool 生命周期应集中管理，CANDIDATE 和 CONFIRMED 初始化逻辑统一
**备份**：`mainline_tracker.py.bak_20260609_pool_init`

```python
# 旧代码
mainline_pool=[]

# 新代码
mp = _sp_by_plate.get(sig.plate, [])
if not mp and lp:
    mp = [{'code': c, 'cum_ret': 0} for c in lp]
mainline_pool=mp
```

**验证**：单元测试通过（模拟 EARLY 信号 + strong_pool → pool 有数据）

### Fix B: 去掉 60% per_cap 仓位限制

**文件**：`quant/trade_plan.py`
**改动**：`_alloc()` 去掉 `per_cap = fp * 0.6`，改为 `return [fp] * n_picks`
**原理**：V4 集中持仓模型，单票可拿满仓
**备份**：`trade_plan.py.bak_20260609_alloc_fix`

```python
# 旧代码
per_cap = int(fp * 0.6)
remaining = fp
allocs = []
for i in range(n_picks):
    a = min(per_cap, remaining)
    allocs.append(a)
    remaining -= a

# 新代码
return [fp] * n_picks
```

### Fix C: CONFIRMED 只取 pool top1

**文件**：`quant/trade_plan.py`
**改动**：`_select_mainline_stocks()` CONFIRMED 分支只取 top1，不取 top3 持仓
**原理**：V4 集中持仓，单主线不分散
**备份**：同 Fix B 备份

```python
# 旧代码：取 top3 持仓 + 新 top1
_top3_codes = set(...)
_held_in_top3 = _held_codes & _top3_codes
if _held_in_top3:
    for _code in _held_in_top3: ...
else:
    _top1 = _sorted_pool[0]

# 新代码：只取 top1
_top1 = _sorted_pool[0]
stocks = [{'code': _top1.get('code', ''), ...}]
```

### Fix E: CANDIDATE 仓位系数 0.8→0.3

**文件**：`config/strategy_rules.py`
**改动**：`MAINLINE_POS_MULT['CANDIDATE']` 从 0.8 改回 0.3
**原理**：对齐 V4 的试探仓谨慎策略（70×0.3=21%）
**备份**：同 Fix D 备份

### Fix F: 多主线每个板块各取 top1

**文件**：`quant/trade_plan.py`
**改动**：`_select_mainline_stocks()` 遍历所有同优先级板块，每个取 top1
**原理**：对齐 V4 多板块策略（每个 CONFIRMED 板块各买 top1）
**备份**：同 Fix B 备份

```python
# 旧代码：只取优先级最高的 1 个板块
_ap, _as = _active_mains[0]

# 新代码：遍历同优先级板块
for _ap, _as in _active_mains:
    _st = _as.get('status', '')
    if _st != _top_status:
        break
    # 每个板块取 top1
```
