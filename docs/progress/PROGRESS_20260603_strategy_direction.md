## 一、主线策略重构方向

### 1.1 核心思路

**先不区分 cycle，统一重构主线策略，再根据数据决定 cycle 怎么分。**

理由：
- 当前按 cycle 区分的策略（冰点期/反弹确认/上升期/下降期）存在大量执行层 bug
- 旧路径没切干净、TRACKER_OVERRIDES 覆盖 hold 天数、信号路由不精确
- 分析结论 vs 回测实际差距大，根因不是策略本身而是执行层
- 应该先统一主线策略，用 338 天数据验证 alpha，再看 cycle 差异

### 1.2 重构步骤

```
Step 1  统一主线策略（不区分 cycle）
        ↓
Step 2  用 338 天数据验证：picks / 胜率 / 均值 / 持仓天数
        ↓
Step 3  按数据聚类看 cycle 差异（哪些 cycle 下 alpha 更强）
        ↓
Step 4  根据差异决定是否需要 cycle 分层
```

## 二、第二条主线检测路径（趋势主线）

### 2.1 问题

CONC 信号依赖"连板型主线"（游资主导），对"趋势型主线"天然覆盖不到：

| 主线类型 | 代表 | CONC 覆盖 | 原因 |
|---------|------|:---:|------|
| 连板型 | 机器人、AI | ✅ | 龙头连板，资金高度集中 |
| 趋势型 | 化工涨价、白酒、储能 | ❌ | 大市值慢涨，无连板，资金分散流入 |

### 2.2 逐月覆盖盲区

| 月份 | Tracker 追踪 | 实际主线 | 差距 |
|------|------------|---------|------|
| 3月 | 机器人概念 21天 | 化工涨价 | 追错板块 |
| 4月 | 外贸 6天（全CAND） | AI算力+白酒+低空 | 完全没确认 |
| 5月 | 军工 7天 | 新消费+核聚变 | 未覆盖 |
| 6月 | 最长2天 | 军工+固态电池+半导体 | 趋势型主线 |

### 2.3 趋势主线信号设计思路

#### 方案 A：行业成交额集中度

```
信号来源：申万一级行业成交额占比
逻辑：连续 N 天 TOP1 行业成交额占比 > 阈值 → 行业主线
优势：不依赖涨停/连板，能捕捉趋势型资金流入
```

#### 方案 B：机构净流入 + 行业排名

```
信号来源：行业资金流向（东财/同花顺）
逻辑：机构连续 N 天净流入某行业 TOP3 → 机构主线
优势：直接追踪"聪明钱"方向
劣势：数据源依赖，实时性可能不够
```

#### 方案 C：板块内个股涨幅分布

```
信号来源：板块成分股 N 日涨幅分布
逻辑：板块内 TOP10 个股 N 日均涨幅 > 阈值 + 涨幅标准差低 → 趋势主线
优势：纯价格数据，无外部依赖
逻辑：趋势主线的特征是"普涨"而非"龙头独涨"
```
