## 二、分析维度与关键发现

### 2.1 D+1涨停+D+2赚钱的D日共性

**4组分布（787只G1涨停股）：**

| 组 | 定义 | 数量 | 占比 | D+2_OC均值 |
|---|---|---|---|---|
| G_A | D+1涨停+D+2赚 | 136只 | 17.3% | +8.75% |
| G_B | D+1涨停+D+2亏 | 40只 | 5.1% | -4.27% |
| G_C | D+1未涨停+D+2赚 | 213只 | 27.1% | +4.37% |
| G_D | D+1未涨停+D+2亏 | 398只 | 50.6% | -4.88% |

**G_A vs G_B 关键差异（同为D+1涨停）：**

| 维度 | G_A(D+2赚) | G_B(D+2亏) | 差异 |
|---|---|---|---|
| D日成交额 | 14.56亿 | 5.46亿 | G_A大2.7倍 |
| D日TO | 8.94% | 6.34% | G_A换手更高 |
| D+1 gap | 5.94% | 7.55% | G_B高开更多 |
| D+1换手率 | 11.64% | 15.16% | G_B筹码松动 |

**核心规律：D日成交额大（流动性好）+ D+1高开不太猛 = D+2更赚钱。**

### 2.4 D+1非一字低吸可行性

**非一字开盘占88.7%（698只），是主要机会。**

不同买点收益对比（非一字698只）：

| 买点 | D+2收益/胜率 |
|---|---|
| open买(开盘追) | -0.20%/42% ❌ |
| **low买(最低点抄底)** | **+3.31%/70%** ✅ |
| close买(尾盘买) | -0.29%/42% ❌ |

**开盘追必亏，低点抄底大赚，尾盘买也亏。**

### 2.5 低吸阈值优化

不同回落幅度的D+2_open_from_low：

| 回落幅度 | n | D+2_open_from_low |
|---|---|---|
| 未回落(>=0%) | 38 | +5.4%/95% |
| **回落0~1%** | **82** | **+4.4%/94%** 🔥 |
| **回落1~2%** | **138** | **+3.9%/89%** |
| **回落2~3%** | **94** | **+3.3%/90%** |
| 回落3~5% | 176 | +2.5%/82% |
| 回落5~7% | 91 | +3.0%/77% |
| 回落7~10% | 64 | +0.7%/58% |
| 回落>10% | 15 | +1.1%/60% |

**规律：回落0~3%是"假摔"（承接强），回落>7%是"真跌"。**

**最优低吸阈值：回落>2%** — 合并D+2=+3.6%/66%，覆盖率85.5%

### 2.6 用户策略验证（一字>2只→只排板，<=2只→排板+低吸）

D日TO<5 & 2+连板（22天，55只）：

| D+1一字数量 | 天数 | 排板D+2 | 低吸D+2 |
|---|---|---|---|
| >2只（3~4只） | 5天 | +5.79%/82% | — |
| <=2只（0~2只） | 17天 | -0.52%/50% | +3.93%/62% |

**一字>2只时市场热，排板D+2=+5.79%/82%；一字<=2只时低吸更好。**

合并结果：纯排板+2.73%/67% → 加低吸+3.07%/65%，覆盖率60%→83.6%

### 2.7 持有天数优化

用户策略（TO<5 & 2+连板）各卖点对比：

| 卖点 | 合并 | 排板 | 低吸 |
|---|---|---|---|
| D+2 open | +3.09%/66% | +2.2%/61% | +5.1%/79% |
| D+2 close | +3.59%/66% | +2.7%/67% | +5.6%/64% |
| **D+3 open** | **+4.55%/62%** | **+4.8%/64%** | +4.0%/57% |
| D+3 close | +2.47%/51% | +1.9%/45% | +3.9%/64% |

**排板最优D+3 open，低吸最优D+2 open/close。持有超过3天收益快速衰减。**

### 2.8 止盈止损分析

| 策略 | 收益/胜率 |
|---|---|
| **无止盈止损, D+2 open卖** | **+3.1%/66%** |
| 无止盈止损, D+3 open卖 | +4.5%/62% |
| 止盈+5%, D+2 open卖 | +2.2%/74% |
| 止盈+3%, D+2 open卖 | +1.0%/77% |
| 止损-3%, D+2 open卖 | +3.0%/55% |
| 止损-5%, D+2 open卖 | +2.4%/57% |
| 止盈+5%/止损-3% | +2.5%/70% |

**结论：不需要止盈止损。止盈砍赢家，止损砍反弹。固定持有1天(D+2 open卖)是最优解。**

## 三、最终方案

### 3.1 策略定位

| 项目 | 内容 |
|---|---|
| 路由 | A路径：hold + 游资主导 + 上升期 Day 1-2 |
| Alpha来源 | 涨停惯性 + 缩量筹码锁定 + 板块动量延续 |
| 预期收益 | D+2 open: +3.1%/66%（正常） / +4.0%/75%（严格） |

### 3.2 D日筛选（收盘后15:30执行）

**严格条件（推荐）：**
```
D日涨停(10cm) + TO<3% + 成交<3亿 + 2+连板
```
- G1天数：16天/41天
- 每日候选：1.6只（中位数1只）
- 策略收益：+4.0%/75%
- 覆盖率：92.3%

**正常条件（备选）：**
```
D日涨停(10cm) + TO<5% + 2+连板
```
- G1天数：22天/41天
- 每日候选：2.5只（中位数2只）
- 策略收益：+3.1%/66%
- 覆盖率：85.5%

### 3.3 D+1执行

```
D+1开盘前:
  对所有候选股挂涨停价排板

D+1开盘后:
  统计一字涨停数量
  
  ┌─ 一字涨停 > 2只 → 只排板，不操作非一字
  │
  └─ 一字涨停 <= 2只 → 排板 + 低吸
      │
      ├─ 非一字回落>2% → 买入
      ├─ 非一字回落>7% → 不买（真跌回避）
      └─ 非一字未回落>2% → 不买
```

### 3.4 持有与卖出

```
D+2开盘: 全部卖出（无论盈亏）

唯一例外: D+2一字涨停 → 持有到D+3开盘卖出
```

### 3.5 不需要止盈止损

- 止盈砍赢家：+5%止盈把收益从+3.1%砍到+2.2%
- 止损砍反弹：-3%止损把胜率从66%砍到55%
- D+2盘中振幅大（回撤-3.1%，反弹+4.1%），设止损容易被洗
- 策略alpha在选股信号质量，不在退出优化

### 3.6 每日选股数量

| 条件 | 每日平均 | 中位数 | 范围 |
|---|---|---|---|
| 严格 | 1.6只 | 1只 | 0~4只 |
| 正常 | 2.5只 | 2只 | 0~7只 |

### 3.7 完整决策流程

```
D日 15:30 收盘后
  ├─ 读取KPH精选50 + CSV日线
  ├─ 筛选: D日涨停 + TO<3% + 成交<3亿 + 2+连板
  └─ 候选池: 约1.6只

D+1 09:15 开盘前
  └─ 对所有候选股挂涨停价排板

D+1 09:30 开盘后
  ├─ 统计一字涨停数量
  ├─ > 2只一字 → 等排板成交，不操作非一字
  └─ <= 2只一字 → 非一字回落>2%时买入

D+2 09:30 开盘
  ├─ 全部卖出
  └─ 唯一例外: D+2一字涨停 → 持有到D+3开盘卖
```

## 五、风险提示

1. **G1天数有限** — 41天中只有16~22天有信号

3. **历史回测** — 过去不代表未来，需要持续验证
