# 2026-05-31 Cycle 重构讨论

## 背景

旧 `quant/style.py` 被删除后，`invest_style` 的计算从 `calc_style()`（欧式距离算法）变为 `anchor_monitor.resolve_style()`（信号查表），导致 cycle 出现多类异常。本次讨论不纠结旧数据对比，而是从零重新设计 cycle 逻辑。

## 一、旧系统的问题

### 1.1 已确认的异常（338天回测数据）

| 类型 | 数量 | 说明 |
|------|:----:|------|
| DECLINE_LONG | 49 | 下降期超 D10，最长 D39 |
| NO_PICKS | 19 | 上升期+主升但 0 picks |
| CYCLE_JUMP | 12 | 上升→冰点，跳过下降期 |
| STYLE_MISMATCH | 9 | 上升期D1+低迷（应为主升） |

### 1.2 根因分析

**CYCLE_JUMP（12次）不是 bug**：这是"突变式退潮"，上升期直接被冰点击穿，是真实的市场形态。

**STYLE_MISMATCH（9次）**：`invest_style` 在 `calc_op` 之前用昨天 cycle 计算，冰点→上升转换日 style 还是昨天的"低迷"。次日 anchor 系统用今天 cycle 重新计算后才修正。这是时序问题，不是逻辑问题。

**DECLINE_LONG（49次）**：`determine_cycle` 没有下降期超时退出机制，prof 在 20-50 之间时一直续下降期。旧 `style.py` 可能在下游做了纠正，但纠正逻辑随 style.py 一起丢失。

**NO_PICKS（19次）**：和 cycle 无关，是 screener 条件或路由问题。

### 1.3 核心结论

cycle 变化的原因是 `invest_style` 的计算方式变了（style.py → anchor_monitor），但 cycle 逻辑本身（`determine_cycle`）没改过。旧 `determine_cycle` 依赖 `invest_style` 做部分判断（下降期→反弹确认期），这个依赖导致了差异。

## 二、重构设计理念

### 2.1 用户核心理念

> cycle 是一个周期、一个循环。万物离不开周期，尤其 T+1 的大 A 市场，顶层大资金的进出需要时间周期来完成。cycle 为超短线操作提供一个较为中线的周期趋势提示。

> 上升和下降的趋势切换，往往伴随着旧结构、旧筹码、旧情绪的出清，新机会的酝酿。冰点期是上升期和下降期之间的节点，是情绪最差、亏钱效应最炸裂的 cycle，盘面通杀。

> 下降期的初期实际上就是快跌到慢跌到反弹再到震荡酝酿新机会的一个过程。

> 对于趋势来说，最难的地方就是判断拐点，所以加入了反弹确认期和上升分歧日来思考拐点。

### 2.2 三个信息源

| 信息源 | 含义 | 灵敏度 | 对应信号 |
|--------|------|:------:|---------|
| sent/prof 趋势 | 全市场体感（大多数人感受到的） | 慢（滞后1-2天） | `sentiment_score`, `profit_score` |
| 强股池信号 | 最灵敏资金的反馈（少数人先感受到的） | 快（当天） | `pool_state`, `CONC_*` 信号 |
| 主线状态 | 资金是否聚焦 | 中 | `tracker_state`, `leader_break` |

## 三、Cycle 完整框架

### 3.1 周期全景

```
                    出清完成
              ┌──────────────────────┐
              │                      │
              ▼                      │
         ┌─────────┐           ┌─────────┐
         │  冰点期   │──────────→│  上升期   │
         │  (出清)   │           │  (赚钱)   │
         └─────────┘           └─────────┘
              ▲                      │
              │                      │
              │    ┌─────────┐       │
              │    │  下降期   │       │
              │    │  (亏钱)   │       │
              │    └─────────┘       │
              │         ▲            │
              │         │            │
              │    突变式退潮          │
              │         │            │
              └─────────┴────────────┘
                   渐进式恶化
```

### 3.2 三个主周期

| 周期 | 核心特征 | 预期持续 |
|------|---------|:--------:|
| **冰点期** | 出清节点，sent/prof 极低，旧结构被打破，新机会酝酿 | 1-2天 |
| **上升期** | 赚钱效应持续，新主线形成，资金正反馈 | 2-15天 |
| **下降期** | 亏钱效应扩散，主线瓦解，资金撤退 | 3-15天 |

### 3.3 下降期内部四个子阶段

| 子阶段 | 全市场特征 | 灵敏资金特征 | 操作建议 |
|--------|-----------|-------------|---------|
| **快跌** | sent/prof 急降，量大，跌停多 | CONC 消失，pool_state→下跌 | 空仓 |
| **慢跌** | sent/prof 缓降，量缩，跌停少 | 无信号，pool_state=横盘 | 观察 |
| **反弹尝试** | prof 短暂回升（>50），sent 跟随 | pool_state→小涨，可能有 CONC_EARLY | 试探，严止损 |
| **震荡酝酿** | sent/prof 横盘（35-55），量能温和 | CONC_WATCH 出现，新主线候选 | 关注，准备入场 |

### 3.4 两种进入下降的方式

| 方式 | 路径 | 特征 | 预警 |
|------|------|------|:----:|
| **渐进式** | 上升→分歧日→确认下降→快跌→... | 有分歧日预警 | 有 |
| **突变式** | 上升→突然退潮冰点 | sent/prof 直接杀到极低，跳过下降期 | 无 |

## 四、拐点判断（核心难点）

### 4.1 拐点 1：下降→冰点（出清完成）

**定义**：旧结构被彻底打破，市场到达最悲观的节点。

| 条件 | 说明 |
|------|------|
| sent < 25 且 prof < 25 | 双杀到位 |
| 或 core_sent < 15 | 情绪极端 |
| 或 prof < 15 | 赚钱效应极端 |
| 无残余 CONC 信号 | 旧主线彻底瓦解 |

**出清完成 = 情绪极低 + 旧结构已破**

### 4.2 拐点 2：冰点→上升（新周期启动）

**定义**：出清完成后，新资金开始进场，新主线形成。

| 条件 | 说明 |
|------|------|
| sent/prof 从极低恢复（core_sent≥30 且 prof>50 且恢复≥15） | 全市场恢复 |
| **且** 有 CONC_CONTRARIAN 或 CONC_CONFIRM 信号 | 新主线出现 |

**关键区别**：
- 有新主线 → 真反弹 → 上升期
- 没有新主线 → 死猫跳 → 反弹确认期（观察）

### 4.3 拐点 3：上升→下降（趋势终结）

**定义**：上升期的赚钱效应消退，资金开始撤退。

| 条件 | 说明 |
|------|------|
| sent<40 且 prof<35（双低） | 趋势确认终结 |
| 或 leader_break 龙头破位 + pool_state 转弱 | 灵敏资金先撤 |
| 或 突变式：sent/prof 直接杀到冰点值 | 无预警退潮 |

**渐进式有预警（分歧日），突变式没有。**

## 五、两个辅助判断工具

### 5.1 反弹确认期

**作用**：下降→上升 的过渡态，等待确认信号。

```
下降期 → prof>50 连续2天 → 反弹确认期
                              │
                    ┌──────────┼──────────┐
                    ▼          ▼          ▼
                新主线出现   prof 持续    prof 回落
                → 上升期    → 震荡期    → 下降期
```

### 5.2 上升分歧日

**作用**：上升期中的早期预警，判断是正常回调还是趋势终结。

```
上升期 → sent<40 且 prof<50 → 分歧日
                                │
                      ┌─────────┼─────────┐
                      ▼                     ▼
                  正常回调                 趋势终结
                  sent 恢复              sent 继续恶化
                  → 继续上升              → 下降期
```

## 六、信号映射（现有架构可用信号）

| 判断 | 数据源 | 信号 |
|------|--------|------|
| 全市场体感 | `sent`, `prof`, `core_sent` | 当日值 + 趋势（vs前日） |
| 灵敏资金状态 | `pool_state` | 大涨/小涨/横盘/下跌 |
| 新主线出现 | `CONC_*` 信号 | CONC_EARLY/WATCH/CONFIRM/STRONG/CONTRARIAN |
| 主线是否活跃 | `tracker_state` | ACTIVE/WATCHING/NONE |
| 龙头破位 | `leader_break` | CONFIRMED/LEADER_BREAK/EXIT |
| 量能 | `amt_total`, `amt_avg_20d` | 大资金参与度 |
| 出清程度 | `freeze` + 无 CONC 信号 | 旧结构是否已破 |
| 赚钱加速度 | `profit_accel`（prof - prev_profit） | 趋势动能 |

## 八、与旧系统的对比

| 维度 | 旧系统 | 新框架 |
|------|--------|--------|
| cycle 来源 | `determine_cycle()` 纯数值判断 | sent/prof + 灵敏资金信号双维度 |
| style 依赖 | 依赖 `invest_style`（calc_style 或 resolve_style） | 不依赖 style，cycle 独立判断 |
| 下降期 | 无超时，无子阶段 | 4个子阶段（快跌/慢跌/反弹/酝酿） |
| 冰点定义 | sent<25 且 prof<25，或单维度极端 | 同左 + 需确认无残余 CONC 信号 |
| 冰点→上升 | prof>50 + core_sent≥30 + 恢复≥15 | 同左 + 需有新 CONC 信号 |
| 上升→下降 | sent<40 且 prof<35 | 同左 + 增加 leader_break + pool_state 辅助 |
| 突变式退潮 | 跳过下降期直接到冰点（被视为 bug） | 正常形态，不视为 bug |
| 反弹确认期 | prof>50 连续2天 | 同左 + 需观察有无新主线 |
| 分歧日 | sent<40 且 prof<50 | 同左 + 增加 leader_break 辅助 |
