## 二、数据分析

### 2.1 数据源

- KPH精选50（`data/kph_sectors/*.json`）— 唯一基准数据源
- kph_jingxuan_full.json + kph_industry_full.json — 全量成分股映射
- CSV日线数据（323天）
- 64个冰点日（排除1个数据不足的日期）

### 2.2 板块级分析：D日KPH强势板块 vs D+1~D+3 TOP20

**核心发现：80.3%的TOP20个股来自D日KPH排名前10板块。**

| 统计 | 数值 |
|------|------|
| 分析样本 | 64个冰点日，1280只TOP20 |
| TOP20命中D日KPH top10 | 1028/1280 = 80.3% |
| TOP20平均D+1~D+3收益 | +24.2% |
| BOT20平均D+1~D+3收益 | -13.0% |
| TOP20正收益概率 | 100%（所有分组） |

### 2.3 板块排名分层命中率

| 排名分层 | 平均每天TOP20命中 | 倍率 |
|---------|-----------------|------|
| rank 1-5 | 2.63 | 1.0x |
| rank 6-10 | 1.40 | 0.53x |
| rank 11-20 | 0.82 | 0.31x |
| rank 21-50 | 0.45 | 0.17x |

**排名前5板块命中率是排名21-50的5.8倍。**

### 2.4 D-1日板块连续性

| 维度 | 平均命中 | 占比 |
|------|---------|------|
| D-1日强势板块(top10) | 14.0/20 | 70.2% |
| D日强势板块(top10) | 15.6/20 | 77.9% |
| 同时在D-1和D | 11.9/20 | 59.3% |

**60%的TOP20个股同时属于D-1和D的强势板块。板块强势有连续性。**

### 2.5 零命中的板块

银行(0/6)、保险(0/4)、酿酒(0/3)、钢铁(0/3)、煤炭(0/3) — 在TOP10但从未贡献TOP20。

### 2.6 板块内个股特征

**单指标排序召回率（rank1-3板块内，取前5%/10%/20%）：**

| 排序指标 | 取前5% | 取前10% | 取前20% |
|---------|--------|---------|---------|
| **上影占比↑（低优先）** | **20.7%** | **32.1%** | **35.7%** |
| D日涨跌幅↓ | 6.4% | 14.1% | 29.5% |
| 振幅↓ | 5.2% | 11.3% | 22.1% |
| 成交额↓ | 4.9% | 10.7% | 20.5% |
| 换手率↓ | 4.2% | 9.8% | 20.9% |
| 量比↓ | 4.1% | 8.7% | 18.7% |

**上影占比是唯一有效的板块内个股筛选指标。**

TOP20个股D日画像：涨得多(+7.7%)、上影线短(22.6% vs 全体26.0%)、收盘在当日高位。

### 2.7 主线信号

| 主线板块KPH排名 | 样本 | TOP20均值 |
|----------------|------|---------|
| 主线rank1-3 | 20 | **+19.2%** |
| 主线rank4-5 | 9 | +17.1% |
| 主线rank6-10 | 4 | +10.3% |
| 主线rank>10 | 5 | +15.2% |
| 无主线 | 25 | +16.7% |

**主线板块的KPH排名比主线存在与否更重要。rank1-3的主线板块TOP20收益+19.2%。**

### 2.8 前序情绪周期

| 前序周期 | 样本 | TOP20均值 | 正收益 |
|---------|------|---------|--------|
| 上升期→冰点 | 25 | +16.0% | 99% |
| 下降期→冰点 | 12 | +18.9% | 100% |
| 反弹确认→冰点 | 3 | +22.3% | 100% |
| 震荡期→冰点 | 7 | +15.3% | 99% |
| 连续冰点 | 16 | +17.0% | 100% |

**前序周期对收益影响不大（都是+15~22%），不适合作为过滤条件，可作为仓位调节因子。**

### 2.9 K线过滤效果 — ⚠️ 不适用

冰点期K线过滤大幅降低召回率，精确率提升有限。综合过滤（换手>15+振幅>4+排除涨停）只覆盖16%的TOP20。

**冰点期的Alpha来源是板块强势延续，不是个股K线形态。K线过滤不适用于冰点期。**

### 2.10 D+1开盘缺口

所有缺口分组都100%正收益，高开略优但差距不大。缺口不是核心变量，不需要跳空过滤。

## 三、方案设计

### 3.1 设计原则

- 以KPH板块排名为核心（覆盖80% TOP20）
- 以主线信号为加分项（+19.2% vs +16.7%）
- 以前序周期为仓位因子
- 不做K线过滤（冰点期不适用）
- 不排除涨停（丢失47.5% TOP20）
- 排除防御板块（银行/保险/煤炭/酿酒/钢铁，零命中率）

### 3.2 选股流程

```
前置条件：cycle_phase 含 "冰点"

Step 1: 加载D日KPH精选50，构建板块排名
Step 2: 选股池 = KPH排名1-3板块的全量成分股
Step 3: 排除 = 防御板块 + ST + 成交额<3000万
Step 4: 板块内排序 = 板块排名优先 → 上影占比升序 → 成交额降序
Step 5: 加分 = 如果该板块是 resonance_top[0]（系统主线），额外加分
Step 6: 取前3~5只
```

### 3.3 仓位规则

| 前序周期 | 仓位上限 | 依据 |
|---------|---------|------|
| 上升期→冰点 | 60% | +16.0%，99%正收益 |
| 反弹确认→冰点 | 60% | +22.3%，100%正收益 |
| 震荡期→冰点 | 50% | +15.3%，99%正收益 |
| 下降期→冰点 | 40% | +18.9%，100%正收益 |
| 连续冰点 | 40% | +17.0%，100%正收益 |

单票上限15~20%。

### 3.4 止损持有

- 止损：-6%（ExitEngine策略级）
- 持有：3天
- 不设止盈，到期按收盘价清仓

### 3.5 与旧方案对比

| 维度 | 旧方案(v7.0) | 新方案 |
|------|-------------|--------|
| 数据源 | kaipanhong260508.json ❌ | KPH精选50 ✅ |
| 选股逻辑 | theme_top背离度 | KPH排名1-3板块成分股 |
| K线过滤 | 零 | 上影占比排序（非硬过滤） |
| 主线信号 | 无 | resonance_top加分 |
| 前序周期 | 无 | 仓位调节因子 |
| 排除涨停 | 无 | 不排除（保留Alpha） |
| 防御板块 | 无 | 排除 |
| 注册方式 | 旧函数直调 | SCREENER_REGISTRY |

### 3.6 预期效果

- 每天候选：~93只（rank1-3板块，排除防御+成交额>3000万）
- TOP20召回：76.3%
- TOP20精确率：11.4%
- 命中均值：+21.2%
