## 三、最终策略方案

### 3.1 优先方案（T1）

| 项目 | 内容 |
|------|------|
| 触发条件 | sent < 30 + 冰点期（cycle_label含"冰点"） |
| 标的 | KPH精选50 Rank2-5板块的龙一或龙二 |
| 买入时机 | **尾盘14:50**，非涨停才买 |
| 持仓周期 | D+2收盘卖出 |
| 预期收益 | D+1=+4.35%, D+2=+3.92% |
| 胜率 | D+1=73%, D+2=53% |
| 频率 | 2年约15次，约1次/月 |
| 仓位 | 40%上限 |

### 3.2 普适方案

**T1买不到时直接跳过**，不做强行替代。

原因：
- 涨停股alpha远强于非涨停股（+2.17% vs +0.19%）
- 能买到的替代品几乎没有alpha
- 冰点期的alpha本质上来自涨停股的D+1延续

### 3.3 操作流程

```
1. 盘中实时监控sentiment_score
2. sent < 30 触发冰点信号
3. 14:30 查看KPH精选50板块排名
4. 确认Rank2-5板块的龙一/龙二
5. 检查是否涨停
6. 14:50 尾盘下单买入
7. D+2收盘卖出
```

## 四、关键发现总结

### 4.1 冰点期的本质

- 冰点日D+1全市场avg=+0.15%，几乎无系统性收益
- 冰点期的alpha集中在**涨停股的D+1延续**，而非普涨
- 94%的龙一在冰点日收盘时已涨停，可操作窗口极窄

### 4.2 理论vs现实的巨大差距

| 口径 | D+1~D+3收益 | 原因 |
|------|------------|------|
| 理论（D日收盘→D+3收盘） | +28.90% | 含D+1涨幅 |
| 现实（D+1开盘买入→D+3收盘） | +0.87% | 高开吃掉收益 |
| 可操作（D日尾盘买→D+2收盘） | +4.35% | 仅限低sent+非涨停 |

### 4.3 板块数据源铁律确认

所有分析严格使用KPH精选50：
- 板块排名：KPH精选50
- 个股归属：KPH精选50
- 强势板块：KPH精选50前序5天统计
- 禁止使用旧板块数据（kaipanhong260508.json等）
