## 六、核心结论

### 6.1 Rotation 策略评估

| 维度 | 结论 |
|------|------|
| 独立 Alpha | ❌ 无（全市场范围内） |
| 最佳子集 | ⚠️ 5天/年，alpha=+1.24%，不够建策略 |
| 实际执行 | ❌ 回测不走 rotation 路由 |
| 性价比 | ❌ 不值得投入 |

### 6.2 Alpha 来源分解

| 来源 | 有效性 | 说明 |
|------|:------:|------|
| 隔夜溢价 | ✅ +2.45% | 选股有关注度，但被日内回吐 |
| D+1 方向 | ❌ 无 | 完全跟随市场方向 |
| 缩量过滤 | ❌ 微弱 | TO≤2% alpha=+0.58% 但中位数负 |
| D-3 深度回调 | ⚠️ 微弱 | +0.39%/55%，不够建策略 |
| 上升期主线低吸 | ⚠️ 有条件 | 7-10天+科技板块有效，但5天/年 |

### 6.3 散乱天路由建议

| 散乱天场景 | 建议策略 | 理由 |
|-----------|---------|------|
| 散乱+上升期 | mainline_rush | beta 正向，已有策略 |
| 散乱+冰点期 | ice_point | 恐慌低吸，已有策略 |
| 散乱+下降D1 | 按 composition 分流 | 走 convergence/board_race |
| 散乱+下降D2+ | **空仓** | 零交易/负 alpha |
| rotation screener | **废弃** | 无独立 alpha，不值得迁移 |
