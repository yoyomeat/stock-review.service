## 一、分析背景

## 二、归因分析：冰点期亏损来源

### 2.1 冰点期前一天的 picks 来源

冰点期的持仓包含两部分：
1. **当天新开仓** — ice_point 策略 picks（D+1 执行）
2. **旧持仓** — 前一天非冰点期的 picks 还没卖完

| 冰点期前一天的策略 | 笔数 | 说明 |
|-------------------|------|------|
| mainline_rush | 20笔 | 上升期主线追涨，带入冰点期 |
| ice_point | 18笔 | 连续冰点 |
| rotation | 17笔 | 轮动期选股 |
| strength | 12笔 | 主升期强度 |
| bounce | 7笔 | 反弹确认 |
| 其他 | 11笔 | board_race/divergence/baotuan等 |

**结论**：冰点期亏损 = 旧持仓亏损（主要）+ 新 ice_point 策略亏损（次要）

## 四、根因总结

ice_point 策略的三个问题叠加：

1. **D+1 能赚钱** — 51.8% 胜率，累计 +39.94%，选股能力不差
2. **持有期是最大杀手** — H2 太长，冰点反弹是一日游，持有期把利润全吐还倒亏
3. **盈亏比差** — 盈利月份单笔 +2~5%，亏损月份单笔 -8~18%

**本质**：冰点期的反弹是短暂的，H2 持有期等来的不是持续上涨，而是继续下跌。

止损不是主要问题（只触发 3 笔，5.4%），**止盈才是关键** — D+1 有利润时没有止盈机制，眼睁睁看着利润回吐变成亏损。
