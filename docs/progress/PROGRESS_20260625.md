## 一、回测NAV暴跌排查与修复

### 1.1 问题
- tracker状态区分（CONFIRMED→CONFIRMED_TREND/CONFIRMED_SIGNAL）后，回测NAV从+186%暴跌到-20%
- 服务器和本地review重跑后结果均变为负数

### 1.2 根因
`mainline_tracker.py:305`中`if prev.status == CONFIRMED:`，因为`CONFIRMED = CONFIRMED_SIGNAL`（别名），这行只匹配`CONFIRMED_SIGNAL`，**不匹配`CONFIRMED_TREND`**。

后果：所有`CONFIRMED_TREND`板块在`update()`循环中找不到匹配分支→直接被丢弃→板块消失→picks大幅减少→NAV暴跌。

### 1.3 修复
- `mainline_tracker.py:305`：`prev.status == CONFIRMED` → `is_confirmed(prev.status)`

## 二、兆易创新入场价错误 + 腾讯CSV空字段问题

### 2.1 entry_points.stock显示错误股票名
- `mainline_confirmed.py`和`mainline_candidate.py`的`stock_label`从`candidates[0]`取值而非`ctx.code/ctx.name`
- 导致entry_points.stock显示主线池第一只股票（如胜宏科技），而非当前pick的股票
- 修复：改为`ctx.code`/`ctx.name`
- **注意：buy_price本身正确**（来自ctx.close）

### 2.2 腾讯API补的CSV空字段导致价格数据丢失（根因）
- 6/18-6/23的CSV由腾讯K线API补充，大量字段为空字符串（涨跌幅、涨跌额、换手率等）
- levistock原生CSV所有字段都有值
- `float(row.get('涨跌幅', 0))`当值为`""`时，`row.get`返回`""`而非`0`，`float("")`抛ValueError
- 被`except (ValueError, TypeError): pass`捕获→整行被跳过→4968只股票全部丢失
- **后果**：6/18-6/23无价格数据→check_exits跳过→持仓到期退出被跳过→held_days超期
  - 兆易创新：entry=493.15, held_days=17, max_days=15（应15天退出但没退出）
- 修复：`float(row.get(...) or 0)`让空字符串→None→or 0→float(0)成功

### 2.3 回测结果变化
| 场景 | NAV | DD | 说明 |
|------|-----|-----|------|
| 修复前（352天本地） | +223% | 50% | 无腾讯CSV，不缺数据 |
| 修复前（355天服务器） | +187% | 50% | 缺3天数据，持仓未正确平仓 |
| 修复后（355天服务器） | +13% | 60% | 全量数据正确，最后3天正常交易 |
| 修复后（352天本地） | +223% | 50% | 不变 |

### 2.4 回测验证（修复后）
- 嘉美包装：+59.39%（修复前-0.10%）
- 大普微：+86.29%（修复前-0.10%）
- 兆易创新到期正常退出（held_days=15, max_days=15）

### 2.5 教训
- `float(row.get(key, 0))`不能处理空字符串：key存在但值为空时返回`""`而非默认值`0`
- 必须用`float(row.get(key) or 0)`确保空字符串→0
- 腾讯API和levistock的CSV格式不完全一致，所有读CSV的代码都需要兼容
- 补数据时需确保所有交易日都有CSV文件，缺失文件会导致价格数据断层

## 三、仓位管理与confirmed策略优化

### 3.1 总仓位上限改为100%
- 原逻辑：`effective_pos = min(final_pos, 100)`，final_pos通常50%→同时只能持1只
- 新逻辑：`effective_pos = 100`，每只pick占50%，允许2只并行
- 回测验证：NAV +272%（与修改前一致，因352天中极少同天双pick）

### 3.2 confirmed_entry买入当天跌>5%次日止损
- 分析发现24笔confirmed中8笔买入当天跌>5%，且100%最终亏损
- 修复：买入当天收盘跌>5%→D+2开盘价卖出
- 回测验证：NAV +223%→+272%，DD 50%→48%
- 7笔被止损，富祥药业省-14.5%，津药药业省-8.8%

### 3.3 confirmed和trend路径独立执行
- 原逻辑：`if has_trend_today: trend else: confirmed`（二选一）
- 新逻辑：confirmed路径始终执行，trend路径在有CONC_TREND信号时额外执行
- 回测验证：交易数38→47，NAV +289%→+241%（新交易有亏有赚）
- 服务器review重跑后需验证0114等日期是否出pick

### 3.4 entry_date修复
- 原逻辑：`_eidx = i - hold_days`（倒推，节假日/T+1偏差）
- 新逻辑：快照`entry_idx_map`，直接查真实入场日
