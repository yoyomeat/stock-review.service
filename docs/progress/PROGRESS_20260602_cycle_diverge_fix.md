## 一、问题发现

在 Strength P1 分析过程中发现上升期 cycle_day 最高到 37，全量扫描发现核心漏洞：

1. **上升期 D3+ 无退出条件**：`_handle_uptrend` 中 cd≥3 直接返回上升期，不检查 sent/prof
2. **分歧日触发条件太严**：需要 sent<40 AND prof<50 同时满足才进分歧日，prof 崩了但 sent≥40 就逃不掉
3. **分歧日→上升期无恢复质量检查**：不满足退出条件时无条件回上升期，47.1% 是弱恢复

## 二、修复方案

### 修改文件

| 文件 | 改动 |
|---|---|
| `quant/position.py` | `_handle_divergence()` 第 653-654 行 |

### 修改内容

```python
# 原代码
# 不满足退出 -> 回到上升期（不重置 day）
return "上升期第%d天" % (cd+1), cd+1, 0.85, streak, ["分歧日结束，回到上升"]

# 修复后
# 不满足退出 -> 检查恢复质量（sent>=40 AND prof>=50 才回上升期）
if sent >= 40 and prof >= 50:
    return "上升期第%d天" % (cd+1), cd+1, 0.85, streak, ["恢复良好回上升(sent=%d,prof=%d)" % (sent, prof)]
else:
    return "上升分歧日第%d天" % cd, cd, 1.0, 0, ["弱恢复延续分歧(sent=%d,prof=%d)" % (sent, prof)]
```

### 阈值选择依据

| 阈值 | 拦截数 | 拦截中差占比 | 放行中差占比 |
|---|:---:|:---:|:---:|
| sent≥50 AND prof≥50 | 10 | 80% | 56% |
| **sent≥40 AND prof≥50** | **8** | **100%** | **45%** |
| prof≥50 | 8 | 100% | 45% |

选择 sent≥40 AND prof≥50：
- 以 prof 为主（prof≥50），sent 放宽到 40（只排除情绪崩盘）
- 拦截的 8 次全部是差/中结果，零误杀
- 比 sent≥50 少误杀 2 个好 case（0808, 0910）
