# PROGRESS_20260622

## KPH50轮换池补充 + 回撤深度分析 + 止损模拟

### 核心成果
- NAV从+44.46%提升到+65.92%（+21.46%），DD 70.12%
- KPH50轮换池补充：check_exits从KPH full补充pool（+21% NAV提升）
- 全量回测：85笔交易，WR=38.8%，PnL=+153.7%

### 一、KPH50轮换补充机制
- 当板块不在D日tracker中时，从KPH full加载板块股票→计算cum_ret→构建补充pool
- cum_ret计算对齐tracker的base_date（从前一日review读取）
- 仅在check_exits路径使用，退潮清仓路径不补充

### 二、仓位管理实验（全部回退）
- 尝试删除17条仓位规则→选股完全改变→NAV暴跌到-63%
- **关键教训**：position计算与选股逻辑深度耦合，position_v2返回0会破坏pick生成
- 正确的仓位优化路径：不能改position_v2，只能改backtest执行层

### 三、退潮清仓分析
- 退潮×1天: 22笔-86%，退潮×2天+: 31笔+384%
- 退潮清仓本身净PnL=+201%，是赚钱的
- 全量KPH full补充退潮→NAV暴跌；条件补充→也变差
- 结论：退潮路径不需要补充，check_exits补充就够了

### 四、回撤深度分析（正确口径：信号日=出信号的D日）

**大亏交易（<=-10%）14笔共性**：
- 信号日dd>=1：9/14笔，覆盖最大风险
- 信号日cycle=下降期：6/14笔
- dd>=1 OR 下降期组合：13/14笔

**信号日dd>=1全量过滤模拟**：
- 过滤44笔(+68.5%)，保留41笔(+85.3%)
- 过滤不能根本解决回撤（PnL从153%降到85%）

**-5%止损全量模拟**：
- 34笔买入日跌>5%的交易：原始亏-300.3%，止损后亏-90.7%，改善+209.6%
- 全量PnL从-88.7% → +120.9%（改善+209.6%）
- 但5笔会被卖飞（合计错过+72.1%）
- 净改善：+137.5%
