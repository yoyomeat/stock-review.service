### 核心发现：旧 G1/G2/G3 分类失效

旧方案按 cycle_day 分 G1（Day 1-2）/ G2（Day 3-6）/ G3（Day 7+），但 Cycle v3 重构后发现：

1. **路由全部合并**：anchor_result 对所有 cycle 都返回 `invest_style='上升健康'` + `action='hold'` + `composition='游资主导'`，导致 84 笔 strength picks 全部走 `('hold', '游资主导', '上升期')` 同一条路由
2. **ROUTE_TABLE 定义的其他路径未生效**：
   - `(enter_aggressive, *, 反弹确认期)` → `strength_bounce` — 0笔
   - `(observe, *, 上升分歧日)` → `None`（不选股）— 实际仍走 strength
3. **G1/G2/G3 划分依据是 screener 内部的 cycle_day**，而 cycle_day 在 Cycle v3 后含义已变

### 3.3 Alpha 归因

P1 的 alpha 不在 G1/G2/G3 的梯度划分，而在 **D+1 的市场反应**：

```
D+1 没跌（low ≥ -5%）→ 赚钱（avg +4.26%, win 79%）
D+1 跌了（low < -5%）→ 亏钱（avg -12.73%, win 0%）
```

G1 表现好不是因为"Day 1-2 的选股逻辑"，而是因为 G1 全部触发在 Day 1，而 Day 1 的票 D+1 往往一字涨停（low≥0）。G2/G3 表现差是因为它们在 Day 2-7 触发，这些天的票 D+1 更容易大跌。
