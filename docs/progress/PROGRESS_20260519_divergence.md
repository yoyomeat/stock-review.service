## 一、分歧日定义

**产生位置**：`quant/position.py` 第 709 行

```python
is_divergence_day = sent < 40 and prof < 50
```

**触发条件**：前日 cycle 是"上升期"，当天 sentiment < 40 且 profit < 50
**cycle_label 格式**：`上升期第N天(分歧日)`
**路由匹配**：`分歧 in ctx.cycle_phase` -> `"divergence"`

**重要区分**：
- position.py 的 `is_divergence_day`（sent<40, prof<50）-> 决定 cycle_label -> 触发 selector 路由
- review_new.py 的 `divergence` 字段（div_high_sent: sent>=60, prof<50）-> 风格层标记，35个日期，与 selector 无关

## 三、板块级分析（4 个过滤后样本）

### 3.1 D-1 top5 板块 -> D+1 表现

| 日期 | D-1 #1 | D #1 | D+1 prof | D-1#1 板块 D+1 表现 |

| 0829 | 芯片 | 锂电池(轮动) | 70 | **D-down +4.38%**, D-up +1.42% |
| 0909 | 氟化工 | 次新股(新) | 55 | D-down -0.06%, D-up -2.41%（全弱） |
| 20260331 | 电子元件 | 轨道交通(新) | 47 | CSV缺失，无法分析 |

### 3.2 发现

1. **"D-1 强板块回调反弹"模式不一致**
   - 0829 芯片：D-down 显著优于 D-up（+4.38% vs +1.42%）✅
   - 0418 食品饮料：D-up 反而优于 D-down（+3.80% vs +1.17%）❌
   - 0909 新材料/机器人/锂电池：全部偏弱 ❌

2. **D 日新晋龙头不一定续强**
   - 0418 建筑地产(D#1)：D+1 不在 top5
   - 0909 次新股(D#1)：D+1 不在 top5
   - 20260331 轨道交通(D#1)：CSV 缺失

3. **板块轮动是常态**
   - D-1 top5 和 D+1 top5 重合度低
   - 分歧日是板块切换窗口，不是简单回调

### 3.3 结论

**没有一个板块级选股模式在 4 个样本中全部有效。** 分歧日的 D+1 恢复更多由大盘整体情绪驱动，而非特定板块。

## 四、选股方案

> ⚠️ **状态：草稿，待进一步数据分析和讨论确认。**
> 以下方案基于 4 个样本的分析，统计信心不足，需要补充更多维度的数据验证后再实施。
> 
> 待确认事项：
> 1. 前置过滤条件是否足够（day<=3 + 非连续）
> 2. 板块级选股模式不一致（0829有效，0418/0909无效），是否需要更细粒度的分析
> 3. 仓位上限 40% 是否合适
> 4. 是否有其他未考虑的选股维度

### 设计原则

基于数据分析结论，分歧日选股不追求"精确抄底某个板块"，而是：
1. **控制风险**：前置过滤排除高风险分歧日
2. **广覆盖**：从多个维度筛选候选，不押注单一板块
3. **质量优先**：选基本面/技术面健康的股票，而非追板块轮动

### 4.1 前置过滤（在 trade_plan.py 层判断）

```python
# 条件1: day <= 3（初期分歧才做）
# 条件2: 非连续分歧日（prev_cycle_label 不含"分歧日"）
# 不满足 -> return []（空仓观望）
```

### 4.2 主选股路径

**Step 1: 加载数据**
- KPH D-1 精选50（板块+成分股）
- CSV D 和 D-1（个股行情）
- plate_to_theme 映射

**Step 2: 主题评分**
- 从 KPH D-1 构建主题：plate_to_theme 映射 -> 按主题聚合
- 计算每个主题的 up_ratio 和 avg_pct
- 排序取 top3 主题

**Step 3: 从 top3 主题的成分股中筛选**

过滤条件：
- D 日涨跌幅: -5% ~ 0%（回调股，排除涨停/跌停）
- D 日成交额 >= 5000 万（流动性）
- D 日换手率 >= 1%（活跃度）
- 量比 < 1.5（不要过度放量）

**Step 4: 评分排序**

```
score = 0
# 板块强度（主题排名越高越好）
score += (3 - theme_rank) * 15  # top1=30, top2=15, top3=0

# 回调幅度（适中回调最佳）
if -3% <= d_pct <= -1%:
    score += 20  # 温和回调
elif -5% <= d_pct < -3%:
    score += 10  # 深度回调

# 流动性（中等成交额最佳）
if 1亿 <= d_amt <= 10亿:
    score += 15
elif 5000万 <= d_amt < 1亿:
    score += 10

# 换手率（活跃但不过热）
if 2% <= d_turnover <= 10%:
    score += 10

# 量比（缩量回调更好）
if d_vol_ratio < 1.0:
    score += 10
elif d_vol_ratio < 1.2:
    score += 5
```

**Step 5: 取前 3~5 只**

### 4.3 Fallback 路径

如果主路径无结果（top3 主题无合适个股）：
- 从 D 当天 KPH top5 板块的回调股中筛选
- 或者沿用前日 picks（当前行为）

### 4.4 仓位

- 3~5 只，每只 10~15%
- 总仓位上限 40%（比原方案保守，因为统计信心不足）
- 止损 -5%（由 ExitEngine 处理）
