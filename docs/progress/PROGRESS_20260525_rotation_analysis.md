## 六、核心结论

### 6.1 rotation 策略的问题

| 问题 | 说明 |
|------|------|
| 无 alpha | D+1 OC=+0.78%/50%，基本是随机 |
| 高波动 | +22.8% 和 -16.1% 共存，风险不可控 |
| 样本太少 | 10 只 rotation pick，统计意义不足 |
| 隔夜溢价被吃 | CC=+3.23% 但 OC=+0.78%，开盘追入必亏 |

### 6.2 散乱天的正确做法

| 散乱天场景 | 正确策略 | 错误策略 |
|-----------|---------|---------|
| 散乱+冰点期 | ice_point ✅ | rotation ❌ |
| 散乱+上升期 | strength/mainline_rush ✅ | rotation ❌ |
| 散乱+下降期D1 | 不做 / convergence ✅ | rotation ❌ |
| 散乱+下降期D2+ | 观望 | rotation ❌ |

### 6.3 建议

1. **rotation screener 迁移优先级降低**：rotation 策略本身无 alpha，不值得花时间迁移
2. **散乱天路由优化**：散乱天应优先走 ice_point（冰点期）或 strength（上升期），而非一律走 rotation
3. **下降期散乱天考虑空仓**：D+1 OC=-0.95%（Day1）至 -0.44%（Day2），不做比做好
4. **rotation 的 CC 口径尚可**：D+1 CC=+3.23%，如果改为 D 日尾盘买入可保留部分 alpha，但这与策略低吸埋伏的定位一致
