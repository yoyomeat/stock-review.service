### 1.1 Strength Screener 全 KPH 扩展（A路径修复）

**问题**: G1/G2 返回 0 候选，因为搜索范围局限于 CONC 板块（50只成分股）。

**修改**:
- `quant/strategies/screeners/strength.py`:

  - 所有 `_select_g*` 增加 `d_kph` 参数，修复 `_get_stock_name(code, None)` name 为空 bug
  - `select_strength()` 增加 CONC → 全 KPH fallback 逻辑

**效果**:

|------|:---------:|:-----:|------|
| G1 | 28/51 (55%) | 8/51 (16%) | -71% |
| G2 | 11/50 (22%) | 6/50 (12%) | -45% |

### 1.3 Strength B路径（反弹确认期）新建

**分析**: 反弹确认期 53 天，连板股整体负收益（-0.57%/46%），但经过筛选后 alpha 显著改善。

**核心发现**:
| 筛选 | 样本 | 收益/胜率 |
|------|------|:------:|
| 2连板全量 | 780笔 | -0.57%/46% |
| +Day1 | 520笔 | -0.26%/48% |
| +TO<3 | 103笔 | +1.77%/61% |
| +CONC内 | 30笔 | +3.28%/67% |

- D+1涨停是唯一正收益来源（涨停 +6.77%/83%，未涨停 -5.70%/20%）
- CONC 内 alpha 远强于 CONC 外
- Day1 >> Day2（+1.77% vs -1.25%）

**新建文件**: `quant/strategies/screeners/strength_bounce.py`

**修改文件**:
- `config/strategy_rules.py` — 新增 `STRENGTH_BOUNCE_SCREENER` + `strength_bounce` 退出规则
- `quant/strategies/screeners/__init__.py` — 注册到 SCREENER_REGISTRY
- `quant/action_router.py` — 4条反弹确认期路由指向 strength_bounce

**策略参数**:
| 参数 | 值 | 依据 |
|------|------|------|
| cycle_day | ≤ 2 | Day3+ 数据稀少 |
| 换手率 | < 3% | TO<3 是关键过滤 |
| 连板 | ≥ 2 | 2连板和3+连板差异不大 |
| 搜索 | CONC→全KPH | CONC内 +3.28%/67% |
| 买点 | D+1 open | 与A路径一致 |
| 卖点 | D+2 open | D+3更差 |
| 止盈止损 | 不需要 | TP7%差异不显著 |

**备份**: `config/strategy_rules.py.bak_20260525_bounce`, `quant/strategies/screeners/__init__.py.bak_20260525`, `quant/action_router.py.bak_20260525_bounce`

**数据**: 反弹确认期 5 天 CONC 是风格板块，其中 2 天产生最大亏损（ST板块 -12.0%, 中报增长 -22.1%）。

**修改**:
- `quant/strategies/screeners/strength.py` — A路径增加 EXCLUDED_PLATES 检查
- `quant/strategies/screeners/strength_bounce.py` — B路径增加 EXCLUDED_PLATES 检查

**行为**: CONC 是风格板块时清空 → fallback 到全 KPH 搜索行业板块候选。
