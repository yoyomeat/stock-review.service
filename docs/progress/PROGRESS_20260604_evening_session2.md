### 2.2 🔴 degraded超限清仓缺少 sold_today 记录（已修复）— **本次关键发现**

**现象**：2025 年 1 月回测中，002917 金奥博在 01-23 被 degraded 超限清仓卖出（@23.10 开盘价），但同日 Step 5 换仓逻辑又重新买入同一只股票（@23.10），01-24 暴跌至 17.61，产生 **-23.76%** 的虚假亏损。

**根因**：Step 2 有两个清仓循环：
1. `degraded_prev` 循环（line 280-286）：有 `sold_today.add(code)` ✅
2. `confirmed_prev` + `plate_degraded >= DEGRADED_EXIT_DAYS` 循环（line 287-295）：**缺少 `sold_today.add(code)`** ❌

第二个循环卖出后没有记录到 sold_today，同时 `plate_degraded[plate] = 0` 重置了 degraded 计数器。Step 5 检查时发现 degraded=0（刚被重置），不触发 `continue`，于是重新买入刚卖出的股票。

**因果链**：
```
01-23 Step 2: degraded超限卖出 002917 @23.10 → sold_today 没记录，degraded 重置为 0
01-23 Step 5: degraded=0 → 不跳过 → 002917 是 pool#1 → 重新买入 @23.10
01-24: 002917 开盘 17.61 → 换仓卖出 → -23.76%
```

**修复**：在第二个循环的 `close_position` 后添加 `sold_today.add(code)`：
```python
# 修复前
portfolio.close_position(code, price_data["open"], date,
                          f"degraded超限({plate_degraded[plate]})清仓·{plate}")
plate_degraded[plate] = 0

# 修复后
portfolio.close_position(code, price_data["open"], date,
                          f"degraded超限({plate_degraded[plate]})清仓·{plate}")
sold_today.add(code)          # ← 新增
plate_degraded[plate] = 0
```

**修改文件**：`scripts/pure_mainline_v3.py`（1 行插入）

| 04-16→04-17 | 002640 | 跨境通 | 3.90 | 3.77 | -3.33% | 两连板后高位接盘 |
| 04-17→04-18 | 001234 | 泰慕士 | 27.20 | 25.00 | -8.09% | **6 连板末日追入** |
| 04-18→04-21 | 001234 | 泰慕士 | 27.31 | 22.47 | **-17.72%** | 连吃两个跌停 |

### 根因

这批全是**事件驱动型连板妖股**：
- 连云港：1 板后追入
- 海鸥住工：连续跌停中抄底
- 跨境通：2 连板后追入
- 泰慕士：**6 连板**末日追入，连吃两个跌停

CANDIDATE 信号在连板末期触发，龙头高度已透支，板块补涨预期已 price in，追入即被套。

### 核心问题

CANDIDATE 只看板块信号，不看龙头高度。当龙头领先板块太多时（连板数过高），入场风险极大。

## 七、下一步优化方向

### 7.1 CANDIDATE 入场过滤 — 龙头高度控制

**问题**：连板数过高的龙头在 CANDIDATE 信号触发时追入，风险极大。

**讨论的方案**：
1. **方案 A：连板数过滤** — 连板 >= 4 直接跳过，= 3 仓位减半
2. **方案 B：龙头与板块偏离度** — 龙头 cum_ret 远超板块均值时跳过
3. **方案 C：不追龙头追板块** — 选板块内 ret5 排名 2~5 的非龙头个股

**推荐方向**：A + C 组合 — 连板 >= 4 砍掉，<= 3 时选板块内排名 2~5 的票

### 7.2 屏蔽低质量板块

外贸（-10.36%、0% 胜率）和中报增长（-7.27%）的 CANDIDATE 信号几乎全亏，可考虑在入场前过滤这些板块。
