## 八、G2最终方案

### 8.1 策略定位

| 项目 | 内容 |
|------|------|
| 路由 | A路径：hold + 游资主导 + 上升期 Day 3-6 |
| Alpha来源 | 涨停惯性 + 缩量筹码锁定 + 板块动量延续 |
| 预期收益 | D+2 open: +6.82%/79%（D+1涨停追入） |

### 8.2 D日筛选

```
D日涨停(10cm) + TO<3% + 2+连板
```
- G2天数：约25天/40天有D+1涨停追入机会
- 每日候选：约1.6只

### 8.3 D+1执行

```
D+1开盘前: 对所有候选股挂涨停价排板

D+1开盘后:
  统计一字涨停数量
  ├─ > 2只一字 → 只排板，不操作非一字
  └─ <= 2只一字 → 排板 + 非一字封涨停时追入

Day 6特殊规则: 跳过一字排板，只做非一字封涨停追入
```

### 8.4 持有与卖出

```
D+2开盘: 全部卖出（无论盈亏）
唯一例外: D+2一字涨停 → 持有到D+3开盘卖出
```

### 8.5 不需要止盈止损

与G1一致。D+2 open固定卖出最优。
