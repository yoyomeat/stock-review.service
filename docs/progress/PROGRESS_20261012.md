# M2 赢家选择层研究（10-12 傍晚~晚间会话，实验 #68~#72c）

## 目标重定（用户拍板）
体系目标 = **找赢家板块**：趋势赢家是顺指数顺风局（逆风抗跌、顺风越涨越猛）；
M2 信号日往往多板块同日触发、不必当日入场——**尽早选出 + 提高选中概率** 是核心目标。

## 实验链（详见 m2_experiment_log.md #68~#72c）
- **#68 全历史捕获率反推（2020+，1854 信号）**：P0 前画像做选择器**证伪**——
  赢家启动前是高 beta 深跌弹性股（dn_ex −0.006 vs −0.004、独涨率更低），不是"逆风抗跌强板块"；
  顺风放大 up_ex W120 唯一弱正（IC+0.18）；分段 2020-24/2025+ 方向翻转。
  与 #35（持有期赢家指纹）、#31（retrospective trap）同构：赢家身份是入场后长出来的。
- **#69 赢家排名分**：承重墙 = cum_ex 持续强于指数；固定赢家口径 IC 随观察窗递增
  （k10 +0.28 → k45 +0.45），Q5 捕获 44% 赢家，2020-24/2025+ 分段双正；
  合成不敌单分（稀释第 3 证）。
- **#70 队内反推口径（用户纠偏）**：cohort=同 P0 日，赢家=队内 MFE100 前 3。
  pick3 覆盖真 top3 = 0.57~0.68（随机 0.34）；pick1 入真 top3 k45 = 0.86。
  零重叠口径衰减至≈随机（确认器非预言家），但赢家 T+45 后剩余 MFE 中位仍 44%（确认即上车不亏）。
- **#71 早选时点 × 指标逐项（用户两点论）**：T+2 窗口太薄不可算，**T+3 为最早可用点**；
  top1 入真 top3：T+3 = 0.60（>50% 线）、T+15 = 0.71。
  指标判决：顺风放大 ✓ / 跌日超额 ✓（T+15 0.66 单指标最佳）/ 独涨率 ✗ 早选无效 /
  个股涨停数 ✗✗ 全档 0.0（妖股反信号第 6 证）/ 回调缩量 ✗✗ 反向 / MA5×13 ✗ 慢信号。
  组合 C4(dn_cap+cum_ex) 唯一有加成。结构洞察：**队内选择 = 相对涨幅排序 + 抗跌微调**。
- **#72/72b/72c 全流水线验收（资金曲线）**：组合层 670 腿仅成交 14 笔（M=3 槽位稀缺）
  ——组合层选谁是最大杠杆。首跑虚高作废（延迟入场按原记录价成交=白送已涨段），
  重定价修正后总收益与 FIFO 打平，但 **W1 MDD −27.5%→−10.7%、胜率 0.43→0.67、
  单位收益中位 −0.06%→+10.3%**；Top3 硬门失效（#28 排序不截断第 4 证）。

## 选择层定稿建议

```
→ 槽位空出按当日新鲜分排队（不用旧排名，#72c 教训）→ 仓位质量加权

```
