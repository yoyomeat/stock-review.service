## 一、思路修正（会话前半，讨论为主）

1. 用户纠偏（最重要）：**不要拿 N 字当目标形态分类**——第一波走的时候不知道它是 N 字；
   真正的问题是"上涨出现了什么特征/什么结构形态/什么技术面条件 → 发现异动开始尝试"。
   一切规则只用 T 日及之前数据。据此废弃 v0 草案的框架层（w3 验收、形态分类）。
2. 用户逐项引导讨论：启动期可捕捉的维度信号 → 最早三信号 → 第三信号时价格位置 →
   指定三指标（站上55日线/MA5金叉MA13/强于指数）有效性 → P0 前后量能共性。
3. 用户拍板：抓坑（黄金坑并入主规则）；MACD 口径改柱收敛+底背离；
   M1 结合方式=历史划段直接锁定 + 未来点位规则判定。

## 九、同日选择力闭环（23:10~23:30，实验 #27/#28）

- 用户纠偏：不接受选日/事件预算框架——技术面=宏观事件的市场反应，同日板块差异应可读。
  我收回#22 证明同日排序是噪声的过度结论（池化对比混淆事件日效应，正确口径=日内 rank IC）。
- **#27**（V1 信号集，37 决策日）：cum_ex3 IC=0.38（32/37 天正）、rs_run/pos60_t3/dev_ma20_t3 ≈0.22、
  drop20/rel20 IC=−0.20（同日跌得深反弹猛）、P0 结构特征无日内选择力。
- **#28**（v1.1 双通道集复核）：B 通道 rev IC=0.24 且 top-k 全优于全保留（k=1 中位 24.4% vs 18.4%）；
  A 通道排序力衰减（cum_ex IC 0.38→0.12，确认门槛 range restriction），top-k 反亏；
  排序≠硬截断：k≤3 任何排序案例回归掉到 0~1/9。
- **定案**：B 同日按 rev 排序取用、A 不排序（全保留/随机采样）、交付=推荐位不截断+M3 从推荐位向下取。

## 十二、主题层排序力试验（10-03 00:40，实验 #31，零 API 本地算）

- 用户方向：技术面难分伯仲 → 结合产业趋势前景 + 消息面排序，用好同花顺数据（注意限流）。
- 数据盘点：ths_api 有封装（令牌桶限流+缓存）；**summaries 仅 5 天历史、news 缓存为空** → 消息面无历史可回测；
  sector.py 有 v6.0 主题关键词组（20 组，覆盖 232/710 板）+ KPH 成分缓存 → 主题特征历史可算。
- **#31 结果**：theme_ret60（产业趋势的 60 日定价代理）**IC≈0、五分位全平**——
  **赢家主题在事件时刻并不显强**（2025-04 底部时 AI 算力链刚被关税砸崩），
  后来的主线无法用过去涨幅识别（retrospective trap）。
  **theme_up60（主题成员>MA60 占比=主题健康度）有效**：池化 IC 0.19、日内 0.15、7/8 天正、Q1 0.50→Q4 0.94；
  **in_theme_rank 负 IC −0.21**（主题内近期低位者弹性大=补涨逻辑）。
- 结论：①可即用 = 病主题过滤（theme_up60 Q1 剔除）+ 主题内低位加分；
  ②产业趋势前景需认知层数据（景气/政策/产业逻辑），价格代理无效；
  ③消息面 L2 建前瞻管道（news 日缓存按主题关键词打标、PIT 时间戳）实盘积累后再评估。
