# PROGRESS_20260629

## 腾讯CSV字段补全

### 问题
腾讯K线API下载的CSV只有8列（交易日/代码/最新价/开盘/最高/最低/成交量/板块），缺失11列。关键字段涨跌幅/涨跌额/昨收价/振幅/股票名称全部为空，导致回测时价格数据断层。

### 方案
- `scripts/fetch_tencent_csv.py`：下载后自动补全昨收价（从前一天CSV取close）、计算涨跌幅/涨跌额/振幅
- `scripts/backfill_tencent_csv.py`：补全现有CSV的股票名称（从levistock CSV链式回溯）
- 服务器6个文件(6/18-6/26)全部修复，关键字段0空值

## 停牌检测

### 问题
停牌股票在CSV中不存在→`load_day_prices`跳过→`check_exits` fallback到`_last_close`→exit价不准。大普微+71%、嘉美包装+53.6%的exit价都是workaround价格。

### 实现
- `backtest_engine.py`：每天对比`open_positions` vs `today_prices`，标记停牌股票（`_suspended_days`累计），每天更新`_last_close`为当日收盘价
- `bt_position_manager.py`（已有逻辑）：无价格数据→跳过，到期时用`_last_close`兜底
