### 2.3 仓位异常发现

**高仓位交易对 NAV 贡献：-21.95%**（占总亏损的绝大部分）。

### 2.4 根因定位

**三个 bug 串联**：

#### Bug 1: `sec['tracker_state']` 与 `mainline_tracker` 不同步

`review_new.py` 中 `sec['tracker_state']` 正确设置，但未序列化到 review JSON。`trade_plan.py` 通过 `sec` 参数读取，运行时正常。**非阻塞问题**。

#### Bug 2: EARLY 升级 `max()` 覆盖仓位（核心 bug）

```python
# trade_plan.py:851（修复前）
if _upgrade_triggered and plan['picks']:
    for _p in plan['picks']:
        _p['allocation'] = max(_p.get('allocation', 0), EARLY_UPGRADE_TARGET)  # 50!
```

所有 50% 仓位交易的共同特征：`prev_signal_level='early'` + `signal_level='confirm'` → 触发 EARLY 升级 → `max()` 将 3% 强制拉到 50%。

#### Bug 3: EARLY 升级不区分 CONFIRMED/CANDIDATE

EARLY 升级调用 `_select_mainline_stocks()` 后，无论返回 CONFIRMED 还是 CANDIDATE，都用 `mainline_candidate` 策略，且不传正确的 `buy_timing`/`hold_days_override`。

## 十一、无 Pick 根因分析与修复 — strong_pool sector 命名不匹配

### 状态：✅ 已修复，全量重跑进行中

### 问题
全量 338 天中有约 120 天 picks=0。经深度排查，发现根因为 **strong_pool 的 sector 字段使用了 CSV 行业层级名称（如"自动化设备/其他自动化设备/机械设备"），与 MainlineTracker 的 KPH 概念板块名（如"芯片"、"人工智能"）完全不匹配**，导致 `_sp_by_plate` 查找永远为空，`mainline_pool` 永远无法被填充。

### 影响链路
```
compute_strong_pool()  → PoolStock.sector = CSV "所属板块" (行业层级)
                                        ↓
MainlineTracker.update()  → _sp_by_plate = {sector: [codes]}  ← key 是行业名
                                        ↓
                           _sp_by_plate.get(tracker_plate)  ← tracker_plate 是 KPH 概念名
                                        ↓
                           返回 None → mainline_pool 永远为空
                                        ↓
_select_mainline_stocks()  → pool 为空 → fallback leader_pool
                                        ↓
                           leader_pool 也空 → 返回 None → picks=0
```

### 数据验证
- 269 个有 CONC 信号的交易日中，mainline_pool 全部为 0 条
- 2670/2690 (99%) 的 strong_pool 代码可通过 KPH 数据映射到正确的板块名
- 86% 的 CONC 板块在 strong_pool 中有代表（14% 为数据限制，非 bug）

### 修复方案（源头修复）

**核心思路：`compute_strong_pool()` 在构建 PoolStock 时，直接使用 KPH 板块名作为 sector，而非 CSV 行业层级名。**

#### 改动 1：quant/anchor_monitor.py
```python
# 签名新增 code_to_plate 参数
def compute_strong_pool(
    today_date, csv_dir, pool_size=POOL_SIZE,
    lookback_days=LOOKBACK_DAYS, min_amount=MIN_AMOUNT,
    max_ret5=MAX_RET5,
    code_to_plate: dict = None,  # ← 新增
) -> list[PoolStock]:

# sector 赋值改为：优先用 KPH 映射，回退 CSV 行业名
sector = (code_to_plate.get(code) if code_to_plate else None) or r.get(所属板块, ).strip()
```

#### 改动 2：quant/review_new.py
```python
# import 新增 _build_code_to_plate
from anchor_monitor import ..., _build_code_to_plate

# 调用顺序：先加载 KPH → 构建映射 → 传入 compute_strong_pool
_kph_data = _load_kph_data(date_str)
_code_to_plate = _build_code_to_plate(_kph_data) if _kph_data else {}
_conc_pool = compute_strong_pool(date_str, args.csv_dir, code_to_plate=_code_to_plate)
```
