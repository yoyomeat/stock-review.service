## 四、G2 Alpha深度拆解 — 找到真正来源

### 4.1 全链路拆解

```
D日涨停 920只
├─ D+1涨停 244只(26.5%) → D+2: +6.82%/79% ✅ Alpha
└─ D+1非涨停 676只(73.5%) → D+2: -2.70%/33% ❌ 亏钱
    ├─ 高开>=5%未涨停: 96只 → D+2: -6.68%/19% 💀 最惨
    ├─ 高开2-5%未涨停: 144只 → D+2: -3.55%/29%
    ├─ 平开-2%~2%: 344只 → D+2: -1.57%/38%
    ├─ 低开<-2%: 92只 → D+2: -1.41%/37%
    └─ 触及涨停但未封住: 133只 → D+2: -2.64%/37%
```

**Alpha只在D+1涨停封死的244只里。高开>=5%未封住最危险（-6.68%）。**

**所有阈值的D+3/D+4均为负或接近0。回撤越深的股票后续越弱。**

## 七、最终结论

### 7.1 Alpha来源总结

G2的alpha由三层决定：

```
第1层（决定性）: D+1是否涨停封死
  └─ 涨停封死: +6.82%/79%
  └─ 未封死: -2.70%/33%
  └─ 差距: 9.5个百分点

第2层（增强）: D+1涨停的盘中质量
  └─ 低开后封涨停: +13.68%/100% (n=19)
  └─ 盘中封死涨停: +13.26%/95% (n=22)
  └─ 连板3+: +8.21%/83%

第3层（过滤）: 成交额>=10亿 或 TO<5 & 2+连板
  └─ 不提升D+1涨停后收益
  └─ 降低非涨停股亏损（全量从-0.17%提到+0.57%）
```

**一句话：G2的alpha是"D+1涨停封死的惯性溢价"，不是"大票流动性溢价"。**

### 7.2 与G1的本质区别

| 维度 | G1 | G2 |
|------|-----|-----|
| D+1涨停率 | ~48% | 26.5% |
| 最优筛选后涨停率 | 80.8% | 63.2% |
| 一字率 | ~82% | ~10% |
| 执行方式 | 排板（提前挂单） | 盘中追入（需盯盘） |
| 未涨停D+2 | -4.77% | -4.77% |
| 期望D+2 | +1.88% | +1.88% |

### 7.3 最终策略方案

```
TO<5 & 2+连板 → 日均2只候选，覆盖22天/40天
├─ 60% D+1涨停 → 涨停追入 → D+2 open卖 → +5.54%/81%
└─ 40% D+1未涨停 → 放弃，不交易

合并期望: +3.63% 每轮
D+2低吸不采用（期望贡献仅+0.30%）
```

### 7.4 与>=10亿方案对比

| 方案 | 日均候选 | D+1涨停率 | 涨停D+2 | 全量期望 |
|------|---------|---------|---------|---------|
| >=10亿（原文S2） | 10只 | 23.8% | +7.83%/87% | +0.57% |
| TO<5 & 2+连板 | 2.0只 | 60.0% | +6.32%/81% | +1.88% |
| TO<5 & DIFF & 2+连板 | 2.1只 | 63.2% | +8.08%/83% | ~+2.5% |

**TO<5 & 2+连板虽然涨停D+2略低(+6.32% vs +7.83%)，但涨停率高2.5倍(60% vs 24%)，全量期望更高。**

### 7.5 不采用D+2低吸的原因

1. 回撤阈值触发买入后D+3/D+4均为负或接近0
2. "买在最低点"的+3%收益是理想化假设，实盘做不到
3. 回撤越深的股票后续越弱（真跌不是假摔）
4. 期望贡献仅+0.30%，不值得增加执行复杂度
