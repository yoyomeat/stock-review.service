# 2026-06-01 Cycle 重构 — 定稿记录

## 状态转换规则（已确认）

### 6个状态
```
冰点期 → 反弹确认期 → 上升期 ⇄ 上升分歧日
              ↓            ↓         ↓
            下降期 ←────────┴─────────┘
              ↓
            冰点期
```

### 转换规则表

| 当前状态 | 出口 | 条件 | cycle_day |
|---------|------|------|-----------|
| 冰点期 | → 反弹确认期 | core_sent≥30 + prof>50 + 恢复≥15 | 重置=1 |

### 冰点三通道（最高优先级，任何状态适用）
- A: core_sent < 25 且 prof < 25
- B: core_sent < 15
- C: prof < 15

### 上升期退出条件（3个，任一满足→下降期）
1. 连续2天三维恶化（每天 pool↓+sent↓+prof↓ 至少2个维度下降）
2. sent < 30 且 prof < 40
3. pool=大跌 且 sent < 40

### 辅助条件（仓位降低但不退出）
4. sent 或 prof 单日 < 50 → cycle_mult 降低
5. pool 连续2天 微跌以下 → 警戒

### 反弹确认期升级规则
- D+2: prof ≥ 60 → 升级上升期（快速确认）
- D+3+: prof ≥ 50 且 core_sent ≥ 45 → 升级上升期（延迟确认）
- D+3+: core_sent < 30 → 下降期（崩盘）
- D+5: 超时 → 下降期

### 下降期→反弹确认期进入条件
- prof ≥ 50 且 core_sent ≥ 60（36次触发，72% D+1 prof持续率）

### 设计决策记录
1. **CONC_EARLY 不作为下降期→反弹确认期的条件** — 下降期有CONC_EARLY的日子占66%，太常见，不构成稀缺信号；且无CONC_EARLY的D+1持续率(64-70%)反而高于有CONC_EARLY(52%)
2. **上升分歧日独立为cycle状态** — 不是上升期子状态，有自己的退出逻辑
3. **分歧日不重置cycle_day** — Day 3进分歧，分歧2天，回来是Day 6
4. **下降期无直接→上升期路径** — 必须经过反弹确认期
5. **冰点检测最高优先级** — 任何状态满足冰点条件都直接进冰点期
