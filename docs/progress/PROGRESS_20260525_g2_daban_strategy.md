    """

    # 3. 如果Day 1-2 → G1逻辑
    # 4. 如果Day 3-6 → 先尝试G2
    # 5. 如果G2无候选 → 回退G2打板

**关键实现细节**:

- **G1筛选**: 当日CSV + KPH，筛选10cm涨停 + TO<3 + 成交<3亿 + 连板>=2
- **G2筛选**: 当日CSV + KPH，筛选10cm涨停 + TO<5 + 连板>=2
- **G2打板筛选**: 当日CSV + KPH，筛选10cm涨停 + 连板>=2 + 成交<5亿
- **G2空窗判断**: G2筛选结果为空时触发打板路径
- **路径标记**: 返回结果中包含 `path='g1'/'g2'/'g2_daban'` 供下游区分
