## 二、时间线口径（铁律）

```
D日 = 上升期Day 2（cycle_label含"上升" + 第2天）
D+1日 = D日的下一个交易日（实际买入日）
D+2日 = D日的下下个交易日

D日收盘后：确认CONC板块，筛选涨停股（候选清单）
D+1开盘：以开盘价买入（实际entry）
D+2/D+3/D+4：持有并择机卖出
```

**结论：TO<8% 主要改善 D+4（+1.05pp），TO 5-8% 是最佳区间。**

### 4.4 Layer 3: gap<3%（28只）— ❌ 反效果

| 指标 | L2后 | L3后 | 变化 |
|------|------|------|------|
| D+2 | +2.27%/57% | **+1.34%/50%** | **-0.93pp/-7pp** |
| D+3 | +3.31%/55% | +0.27%/50% | **-3.04pp/-5pp** |
| D+4 | +2.76%/62% | **-0.09%/57%** | **-2.85pp/-5pp** |

gap分层（L2基础上）：

| gap | 只数 | D+2 | 胜率 |
|-----|------|-----|------|
| -2~0% | 6 | +1.79% | 67% |
| 0~2% | 16 | +2.65% | 50% |
| **5~10%** | 7 | **+4.30%** | **71%** |
| 10~20% | 4 | +3.43% | 50% |

**结论：gap<3% 过滤反效果！高开5~10%的反而最好（+4.30%/71%）。**
**涨停股的高开是延续强势，不是追高被套。应去掉此过滤。**

## 七、Alpha来源

1. **上升期延续性**：Day 2 确认上升期没断，板块趋势延续
2. **板块拥挤度控制**：CONC涨停<30排除过度拥挤板块
3. **低换手=抛压轻**：TO<8%的封板稳定，次日延续性强
4. **STRONG比MEDIUM强**：prev_max≥8 或 block_max≥7 的上升期延续性更好

```python
def select_mainline_rush(date_str, max_picks=1, **kwargs):
    review = load_review(date_str)
    cycle_day = review['cycle_day']
    
    if cycle_day == 2:
        strength = _classify_strength(review['cycle_history'])
        if strength == 'EXCLUDE':
            return []
        return _select_day2(date_str, max_picks, d_kph, strength)
    
    if cycle_day in (4, 5, 6):
        return _select_day46(date_str, max_picks, d_kph, cycle_day)
    
    return []  # Day 1, 3, 7+ 不做
```
