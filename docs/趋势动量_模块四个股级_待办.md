## 三、候选研究问题（启动时细化并预注册）

1. **板块内选股**：稳/妖轴 + 主题内排位 + 相对强度，能否稳定区分板块内赢家？（个股 PIT 特征已在 stock_daily.db）
2. **个股入场**：跟板块 P0 同步 vs 等个股自身结构确认（个股 sdw 同构判据）？
3. **个股出场/仓位**：M3 的 sdw 低点锚 / chandelier / 风险预算逐字下沉 vs 个股波动率重标定？
4. **龙头 vs 补涨配置**：主题内低位补涨（负 IC 但弹性）与稳龙头的仓位权重。
5. **可回测性边界**：个股层的选择质量部分不可回测（同人工聚焦哲学）——机制验证 vs 选择质量分开承诺。
